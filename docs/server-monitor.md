# 管理员监控模式

`group.moderator`、`group.custodian` 管理组的玩家可在游戏内使用：

| 命令 | 用途 |
| --- | --- |
| `/monitor` | 开启或退出监控 |
| `/monitor <玩家>` | 固定观察指定玩家；已开启时切换目标，保留最初返回位置 |
| `/monitor stop` | 退出监控；未开启时不执行操作 |

开启后切换为旁观模式，优先从目标侧面略偏后、略高的位置进行第三人称观察，同时取景玩家身体与实际操作的方块或实体，包括向上建造和向下挖掘。短暂转头、横移或折返不会让镜头随移动方向绕圈；持续改变朝向后，镜头带惯性地调整观察方向。三维跟随使用阻尼与速度延续，起步逐渐加速、急停后短暂滑行再收住，跟随位置相对所选机位最多落后约 0.75 格。

操作目标优先采用最近的点击、挖掘、放置、实体交互或直接攻击记录，最多保留 12 tick（约 0.6 秒）；移动中的实体会持续更新位置。转头明显离开、超出附近交互范围、传送或切换目标后清除记录。没有近期交互时，沿玩家当前准星识别交互范围内最近的方块表面或实体，按各自交互距离判定，并让方块遮挡实体；感知范围最多 16 格，只查询已加载区域。未命中实际物体时，才参考平滑朝向前方约 3 格的位置。

取景同时检查玩家和物体的包围盒，按两者在画面中的夹角安排注视方向，并采用监控者的 [FOV 设置](spatial-menus.md)，在视野边缘预留 5°。该设置应与客户端 FOV 保持一致。候选机位必须同时看清玩家与实际操作面，也不能让玩家身体挡住操作点；必要时尝试换侧、调整高度或拉远至 8 格。惯性过渡中的同框、方块遮挡和身体遮挡也会分段复查，不能保持清楚时直接切镜。

每 tick 更新跟随位置，通过仅向监控者发送的虚拟旁观玩家镜头让客户端插值移动，并保留墙内可视规则；镜头不加入世界、不出现在 Tab 中。目标传送（包括同世界短距离传送）后，以传送完成的位置和朝向重新选点并重建镜头，清除原有跟随惯性；初次显示和后续转向同时同步镜头身体与头部朝向，静止画面不重复发送移动包。高速移动不按单 tick 位移重新选边。

正常移动时水平观察半径约 4.5 格；持续高速移动时逐渐增大，最高 8 格，并沿稳定的三维移动方向加入最多 1 格的位置补偿。补偿调整机位，构图继续兼顾玩家与操作区域。正常走路和小幅交替移动不触发拉远；急停、减速时回收距离，急转或折返时撤回旧方向补偿，待新方向连续稳定后恢复。传送、切换目标和跨世界会清除原有速度估计。预测位置受阻时优先保留清晰的未补偿视角，拉远和补偿均遵循世界边界、已加载区块与避障规则。

未指定玩家时，每 30 秒随机选择下一个目标，一轮中每名可观察玩家只出现一次；存在其他目标时，换轮也不会连续观察同一个人。屏幕操作栏显示当前目标。

自动轮播目标排除自己、其他监控者、实际无操作的 AFK 玩家、旁观玩家、死亡玩家、离线玩家和当前管理员不可见的玩家。AFK 排除须同时满足挂机状态和至少 3 分钟无有效输入，刚输入或反复使用 `/afk` 不会立即获得豁免。当前目标满足这一挂机条件或失效后自动换人；暂时无人可观察时保持旁观并等待，新目标出现后继续。

使用 `/monitor <玩家>` 时不会自动轮换，允许手动查看 AFK 玩家；仍排除自己、其他监控者、旁观、死亡、离线和不可见的玩家。指定目标暂时失效时等待同一账号恢复，不会改为观察其他玩家。用 `/monitor stop` 或 `/monitor` 退出。

监控者的游戏内实体对非管理玩家隐藏，包括普通旁观玩家。正在监控的管理员之间也互相隐藏实体，观察同一玩家或机位重叠时不会相互遮挡；未开启监控的管理组仍可看见。普通玩家的 Tab 保留监控者正常在线条目、姓名与原游戏模式的展示。管理组的 Tab 显示真实旁观状态，监控者姓名末尾额外显示本地化的 `[监控]` / `[Monitor]` 标记，普通玩家看不到；互相隐藏实体的监控者也保留这些 Tab 条目。监控者本人的客户端保留真实旁观状态，以启用墙内可视。开启和退出时立即刷新双方可见性。玩家加入或管理角色变化时同步可见性。退出并成功返回后恢复实体可见性，返回失败时继续隐藏。

普通玩家不能通过原版实体目标命令（如 `/tp`、`/teleport`、`/spectate`）指定监控者；直接姓名、UUID 和选中监控者的选择器均拒绝执行。原生旁观菜单的目标传送和视角附着同样拦截。管理组可正常操作。

监控者不计入其他玩家的“附近玩家隐身”人数和最近距离。此豁免只在监控会话中生效，普通隐身玩家仍正常统计。监控中的旁观移动不会写入 `/back` 历史，也不会触发传送场景提示。

监控期间暂停自动 AFK，并排除活动奖励；自动跟随不刷新活动时钟。已经 AFK 时主动开启监控会解除挂机保护，但不恢复奖励资格。监控中手动进入 AFK 会结束监控并返回原位置，保留手动 AFK 状态。退出、掉线或插件关闭时释放豁免，按原有活动时间恢复判定。

跨世界跟随或监控者切换世界时保持监控；世界管理插件在换世界时应用的默认游戏模式会在下一 tick 恢复为旁观，不覆盖开启前保存的状态。退出时返回开启前的位置，恢复原游戏模式与飞行状态。手动通过 `/gamemode` 或原版游戏模式切换器改为其他模式，即使紧接在换世界之后，也会结束监控、返回原位置，并保留新选择的游戏模式；管理权限被撤销也会自动退出。退出游戏和插件关闭时清理会话并恢复玩家状态。

镜头可进入墙体观察。开阔处采用无遮挡侧视；有墙阻挡时，尝试把镜头的眼睛位置放进完整实体墙体内，利用旁观模式的可视规则保持第三人称。判断针对眼睛所在方块，脚底可以留在墙外；半砖、楼梯、玻璃等按实际渲染状态区分。

当前视角仍可用时，新的候选视角须连续 5 tick 更好才换位；当前视角失效时立即避让。连续移动会分段检查视线和插值朝向；中途遮挡、穿越暴露墙面或朝向偏离过大时直接切镜。切镜先挂接新镜头，再移除旧镜头，避免短暂回到监控者自己的视角。过渡检查有步数上限，异常长位移直接切镜。

墙内视角会检查穿出这片实体墙体后看向玩家和操作面的方向，墙后的空气空腔和另一堵独立墙仍可能遮住目标。平滑跟随时持续复查这一条件，避免镜头滑到被墙遮挡的空气位置。相邻实心方块内部允许连续移动，安全留白只作用于暴露墙面。选点优先保持已有视角；确实无法同时看清玩家和操作面时，暂用原生第一人称旁观以保留操作视角，条件持续恢复约 1 秒后再切回第三人称。

第三人称选点保持在世界边界内，遮挡查询只在已加载的区域执行。正常退出需要的返回区块在后台加载，完成后再返回；若返回被其他插件拒绝，会保留监控会话，可用 `/monitor stop` 重试。退出游戏或插件关闭时立即尝试返回，不等待后续任务。
