# 管理员监控模式

`group.moderator`、`group.custodian` 管理组的玩家可在游戏内使用：

| 命令 | 用途 |
| --- | --- |
| `/monitor` | 开启或退出监控 |
| `/monitor <玩家>` | 固定观察指定玩家；已开启时切换目标，保留最初返回位置 |
| `/monitor stop` | 退出监控；未开启时不执行操作 |

开启后切换为旁观模式，优先从目标侧面略偏后、略高的位置进行第三人称观察，同时取景玩家身体与实际操作的方块或实体，包括向上建造和向下挖掘。短暂转头、横移或折返不会让镜头随移动方向绕圈；持续改变朝向后，镜头带惯性地调整观察方向。三维跟随使用阻尼与速度延续，起步逐渐加速、急停后短暂滑行再收住，玩家平移造成的跟随滞后最多约 0.75 格。机位换侧、升降、拉近拉远与镜头转向分别保留速度，大幅换位逐渐完成，反向调整时先减速。

操作目标优先采用最近的点击、挖掘、放置、实体交互或直接攻击记录，最多保留 12 tick（约 0.6 秒）；移动中的实体会持续更新位置。转头明显离开、超出附近交互范围、传送或切换目标后清除记录。没有近期交互时，沿玩家当前准星识别交互范围内最近的方块表面或实体，按各自交互距离判定，并让方块遮挡实体；感知范围最多 16 格，只查询已加载区域。未命中实际物体时，才参考平滑朝向前方约 3 格的位置。

取景同时检查玩家和物体的包围盒，按两者在画面中的夹角安排注视方向，并采用监控者的 [FOV 设置](spatial-menus.md)，在视野边缘预留 5°。该设置应与客户端 FOV 保持一致。候选机位必须同时看清玩家与实际操作面，也不能让玩家身体挡住操作点；必要时尝试换侧、调整高度或拉远至 8 格。惯性过渡中的同框、方块遮挡和身体遮挡也会分段复查，不能保持清楚时直接切镜。

每 tick 更新跟随位置，通过仅向监控者发送的空物品展示实体作为虚拟镜头，让客户端插值移动，并保留墙内可视规则；镜头不加入世界、不出现在 Tab 中。镜头在接管前设置为一 tick 的位置与转向插值，使客户端跟随时长与每 tick 更新频率一致。目标传送（包括同世界短距离传送）后，以传送完成的位置和朝向重新选点并重建镜头，清除原有跟随惯性；初次显示和后续移动均同步镜头朝向，静止画面不重复发送移动包。高速移动不按单 tick 位移重新选边。

第三人称观察时，目标玩家的移动包仅对当前监控者转换为单终点插值，减少高速飞行时分段采样造成的人物忽快忽慢。相对移动按原发送基准逐包解码，保留终点、朝向与着地状态；合并路径时保留各分段的总时长，单 tick 更新与多 tick 合并更新均按原时长播放，大位移不会截断为短整数。此处理不改变目标玩家的实际位置或其他玩家收到的数据。切换目标、跨世界、退出、暂停跟随或退回原生第一人称时释放处理；乘坐载具时保留原生移动同步。

正常移动时水平观察半径约 4.5 格；持续高速移动时逐渐增大，最高 8 格，并沿稳定的三维移动方向加入最多 1 格的位置补偿。补偿调整机位，构图继续兼顾玩家与操作区域。正常走路和小幅交替移动不触发拉远；急停、减速时回收距离，急转或折返时撤回旧方向补偿，待新方向连续稳定后恢复。传送、切换目标和跨世界会清除原有速度估计。预测位置受阻时优先保留清晰的未补偿视角，拉远和补偿均遵循世界边界、已加载区块与避障规则。

未指定玩家时，每 15 秒从所有监控者共用的加权公平队列选择目标。队列按实际成功观察的时长分配机会，同身份玩家尽量均匀覆盖；每名非 member、member、管理、维护玩家的权重分别为 **8∶4∶2∶1**，身份按最高角色判断。权重表示每人的相对观察频率，各组总占比随可观察人数变化。存在其他未被占用的目标时不连续观察同一人，因此人数很少或部分目标不可见时，实际比例受可用目标限制。屏幕操作栏显示当前目标。

自动轮播不重复分配已被其他监控者观察的玩家，手动指定的目标也占用这一分配；手动观察仍可重复指定，并计入已观察时长，同一玩家被同时观察只累计一份覆盖时间。目标全部有人观察时，多余的自动监控者等待，目标释放后继续；手动指定与自动目标重叠时，自动监控者在下一 tick 重新分配。

新玩家按队列当前进度加入。离线、实际无操作的 AFK 或对全部自动监控者不可见期间不积攒优先级，恢复时保留此前已获得的观察记录并衔接当前队列进度。暂时不再可观察的记录保留 30 分钟，插件关闭时清理；短暂重连、切换 AFK 或重开监控会话不会清空这份共享记录。

自动轮播目标排除自己、其他监控者、实际无操作的 AFK 玩家、旁观玩家、死亡玩家、离线玩家和当前管理员不可见的玩家。AFK 排除须同时满足挂机状态和至少 3 分钟无有效输入，刚输入或反复使用 `/afk` 不会立即获得豁免。当前目标满足这一挂机条件或失效后自动换人；暂时无人可观察时保持旁观并等待，新目标出现后继续。

使用 `/monitor <玩家>` 时不会自动轮换，允许手动查看 AFK 玩家；仍排除自己、其他监控者、旁观、死亡、离线和不可见的玩家。指定目标暂时失效时等待同一账号恢复，不会改为观察其他玩家。用 `/monitor stop` 或 `/monitor` 退出。

监控者的游戏内实体对非管理玩家隐藏，包括普通旁观玩家。正在监控的管理员之间也互相隐藏实体，观察同一玩家或机位重叠时不会相互遮挡；未开启监控的管理组仍可看见。普通玩家的 Tab 保留监控者正常在线条目、姓名与原游戏模式的展示。管理组的 Tab 显示真实旁观状态，监控者姓名末尾额外显示本地化的 `[监控]` / `[Monitor]` 标记，普通玩家看不到；互相隐藏实体的监控者也保留这些 Tab 条目。监控者本人的客户端保留真实旁观状态，以启用墙内可视。开启和退出时立即刷新双方可见性。玩家加入或管理角色变化时同步可见性。退出并成功返回后恢复实体可见性，返回失败时继续隐藏。

虚拟镜头没有展示物品，也没有玩家皮肤或头部模型，即使在高速后退、切镜或客户端第三人称下也不会绘制默认皮肤。镜头位置直接使用取景眼睛坐标，监控者本身的体型与属性保持原值。切镜先挂接新镜头再清理旧实体；等待目标、退回原生视角、退出及插件关闭时释放镜头。

普通玩家不能通过原版实体目标命令（如 `/tp`、`/teleport`、`/spectate`）指定监控者；直接姓名、UUID 和选中监控者的选择器均拒绝执行。原生旁观菜单的目标传送和视角附着同样拦截。管理组可正常操作。

监控者不计入其他玩家的“附近玩家隐身”人数和最近距离。此豁免只在监控会话中生效，普通隐身玩家仍正常统计。监控中的旁观移动不会写入 `/back` 历史，也不会触发传送场景提示。

监控期间暂停自动 AFK，并排除活动奖励；自动跟随不刷新活动时钟。已经 AFK 时主动开启监控会解除挂机保护，但不恢复奖励资格。监控中手动进入 AFK 保持监控，继续允许监控跟随与退出返回；手动 AFK 状态保留到按 AFK 规则解除。退出、掉线或插件关闭时释放豁免，按原有活动时间恢复判定。

监控会话仅在手动执行 `/monitor`、`/monitor stop` 或主动切换游戏模式时退出。AFK、管理权限变化、跨世界跟随和监控者切换世界均保持已有会话；开启新会话和指定目标仍校验管理权限，已有会话始终允许手动退出。插件被动改变的游戏模式会在下一 tick 恢复为旁观，不覆盖开启前保存的状态；恢复被拒绝时保留会话并暂停跟随，恢复旁观后继续。退出时返回开启前的位置，恢复原游戏模式与飞行状态。手动通过 `/gamemode` 或原版游戏模式切换器改为其他模式，即使紧接在换世界之后，也会结束监控、返回原位置，并保留新选择的游戏模式。退出游戏和插件关闭时清理会话并恢复玩家状态。

镜头可进入墙体观察。开阔处采用无遮挡侧视；有墙阻挡时，尝试把镜头的眼睛位置放进完整实体墙体内，利用旁观模式的可视规则保持第三人称。判断针对眼睛所在方块，脚底可以留在墙外；半砖、楼梯、玻璃等按实际渲染状态区分。

当前视角仍可用时，新的候选视角须连续 5 tick 更好才换位；当前视角失效时立即避让。大角度换位优先沿玩家周围较短的弧线绕行，该路线无法保持取景或避开遮挡时尝试另一侧；选定后保持绕行方向，避免在两侧来回翻转。转向与俯仰逐渐加速、收住，跨越 ±180° 时沿短角度衔接；阻尼会在玩家或操作对象接近画面边缘时适当减弱，以保持同框。

连续移动按位移和转角分段检查视线、同框和客户端插值朝向。两侧路线均不可用、当前视角已经遮挡、穿越暴露墙面或朝向偏离过大时直接切镜；切镜重新采用清晰机位并清除过渡速度。切镜先挂接新镜头，再移除旧镜头，避免短暂回到监控者自己的视角。过渡检查有步数上限，异常长位移直接切镜。跨目标、传送、跨世界及原生第一人称与第三人称之间仍切镜，不沿不连续或无法兼顾身体与操作面的路径移动。

墙内视角会检查穿出这片实体墙体后看向玩家和操作面的方向，墙后的空气空腔和另一堵独立墙仍可能遮住目标。平滑跟随时持续复查这一条件，避免镜头滑到被墙遮挡的空气位置。相邻实心方块内部允许连续移动，安全留白只作用于暴露墙面。选点优先保持已有视角；确实无法同时看清玩家和操作面时，暂用原生第一人称旁观以保留操作视角，条件持续恢复约 1 秒后再切回第三人称。

第三人称选点保持在世界边界内，遮挡查询只在已加载的区域执行。正常退出需要的返回区块在后台加载，完成后再返回；若返回被其他插件拒绝，会保留监控会话，可用 `/monitor stop` 重试。退出游戏或插件关闭时立即尝试返回，不等待后续任务。
