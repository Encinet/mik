# 地段选区与子地段

创建地段、编辑范围和创建子地段共用选区组件，使用独立编辑上下文和草稿。进入编辑后，用 `//pos1`、`//pos2` 标记当前位置；也支持 `//pos1 x,y,z`、`//pos2 x,y,z`，纵坐标必须在当前世界高度范围内。这些命令通过事件接管，不另行注册；会话外仍交给 WorldEdit。面板打开或只显示边框时也能标点，不必先切换选点模式。

## 组合形状

- 「累加当前框选」加入另一段，可组合相连房间和不同高度的区域。
- 「扣除当前框选」移除整块 4×4×4 单元，可留出庭院或空洞。
- 完整的两点就是当前待保存范围；直接保存会替换整个地段范围，不另设「替换笔刷」步骤。只有一个点时不能保存，也不修改已有地段。
- 多区域需要先点「累加当前框选」或「扣除当前框选」，系统合并后清掉两点，便于继续选择下一段。没有新两点时，保存整理后的整体范围。
- 「重选两点」只清掉当前两点，保留已整理的范围；编辑已有地段时，「恢复已保存范围」从真实单元集合重新载入。每份草稿各自维护撤销／重做。

所有组合操作向外对齐 4×4×4 网格，负坐标向下取整，不限制面积、体积或网格单元数量。重叠单元自动去重；当实际单元完整覆盖外包长方体时，自动整理为一个长方体草稿，减少单元存储及轮廓计算。未完整覆盖时保留实际单元，不填孔洞，不跨空隙连接不同区域。保存地段的范围仍必须相连，并重新校验重叠、子地段与到访点。

长方体选区的尺寸与边框直接从网格对齐后的角点计算，预览不展开整个单元集合。扣除操作仅检查现有选区单元是否落在扣除框内，不为巨大扣除框逐格分配内存。沙盘与粒子的显示预算仅约束展示开销，不限制地段大小。

撤销／重做完整恢复两点、组合形状和进行中的矩形调整，共保留最多 16 步。撤销后实际修改会清空重做分支，无变化操作不占用历史。草稿按玩家和地段隔离。实地选点时只接管木斧左右键，其余工具与空手仍可正常使用；潜行＋F 或 `/plot edit` 返回面板。Actionbar 只显示两条标点命令、完成标记和对齐后的选区尺寸，不混入坐标、单元数量及长篇操作说明。

## 单个矩形管理

整理后的形状可在同一范围编辑器内进入「矩形管理」。这里的矩形是三维长方体：完整长方体直接显示为一个矩形；组合形状按高度、深度、横坐标的固定顺序取起点，先横向扩展，再沿深度和高度合并。每个单元只属于一个矩形，保留孔洞和不相连区域，不扫描空的外包空间，也不承诺得到数学上最少的矩形数量。

左侧按编号列出矩形，中央沙盘用灰线和编号显示本页矩形，右侧显示所选矩形的尺寸、两角坐标和操作。点击列表后沙盘自动聚焦该矩形，并以绿色高亮；视角按钮可返回总览。翻页也返回总览，避免继续聚焦上一页的矩形。每页六个只是列表和边线的展示预算，不限制可拥有的矩形数量。

- 「调整此矩形」预填当前矩形的两角。此时 `//pos1`、`//pos2` 和木斧只修改该矩形，其他矩形保持不变；沙盘同步显示整体候选边界和调整后的绿色矩形。
- 「完成矩形调整」将结果合并回整体草稿，重叠自动去重。调整完成前不能保存地段或执行整体累加、扣除、恢复范围；缺少角点时不能完成调整。
- 「取消矩形调整」或调整中的返回按钮恢复进入调整前的完整草稿和两点，回到矩形管理。撤销／重做也可恢复调整过程。
- 「删除此矩形」先显示编号和范围的确认页，只从草稿移除该矩形，不删除建筑。删除最后一个矩形得到空草稿，仍可撤销，但不能保存为空地段。
- 完成调整或删除后，仍需统一保存地段才会改变保护范围。保存继续检查最新权限、整体相连性、重叠、子地段和到访点，失败时保留草稿供继续修正。

编号由当前几何生成，相同形状得到相同编号；合并或删改后可能重新编号，不作为地段 ID，也不写入数据库。操作以草稿版本和完整矩形边界校验目标，不能用旧页面的编号误删新的矩形。分解结果按草稿版本缓存，转动沙盘和玩家移动不重新分解；调整候选只在两点变化时计算。Bedrock 原生表单复用同样的编号、调整、删除流程，不采样沙盘地形。

## 中央沙盘与控制台

总览按网格对齐后的候选范围计算窗口，不再用原始角点矩形裁剪待保存边线。水平采样步长按 X/Z 各轴独立确定，只有总预算不足时才共同加粗；长窄范围不再因为长轴超过 128 点，就连带丢掉短轴的一格厚墙。采样窗口与显示留白分离：与世界合法高度相交时只采样该交集，完整 384 格世界不会因上下预览留白变成隔层采样。切换剖切只读取当前玩家高度，不改变已固定的聚焦窗口；切到其他高度的矩形不会覆写原剖切高度，层调整则从当前实际可见切面逐格移动。

范围编辑器以中央立体沙盘为预览主体，浅弧控制台位于后方与两侧。左侧负责实地选点和组合笔刷，右侧负责保存、历史以及视角，退出和返回位于沙盘下方。控件按真实文字与图标尺寸排列，中央模型区域保留独立空间；模型不拥有点击命中盒，不能通过点击沙盘设置角点或改变世界。

青色边线表示已保存范围，绿色与金色标记两个角点，紫色表示当前页面待保存的网格边界。不再叠画一套原始两点长方体；待保存边界与已保存范围相同时也不重复绘制。提交、沙盘和实地预览共用同一份待保存范围：有完整两点时显示两点范围，没有两点时显示已整理的形状；只有一个点时不显示待保存轮廓。边线保留不规则轮廓和空洞，不以外包长方体冒充实际范围。白色标记是玩家，红色标记表示水平朝向。

沙盘提供立体和固定北向的俯视平面，标注 N/−Z 和 E/+X。立体视图每次旋转 45°；俯视时旋转按钮禁用，返回立体后恢复原来的朝向。「仅显示边界」隐藏建筑地形并停止采样，用于核对不规则边界与空洞，不改变选区。总览包含已保存范围、组合形状与完整笔刷；「聚焦我附近」以点击时的位置为中心显示约 25×16×25 方块，也可在矩形列表中聚焦指定矩形。

剖切起始高度为点击时玩家所在方块上方两格，可逐格上移或下移，页面显示实际剖切 Y 值；切回完整高度恢复整个模型。剖切只影响预览，不改方块、选区、保存内容或撤销历史；返回同一地段编辑页保留视角。首次载入保存范围不占用撤销步骤，保存失败保留编辑上下文。

采样窗口总计最多 32768 点，水平每轴最多 128 点，高度最多 384 层。窗口可容纳时逐块读取，默认附近窗口的 10000 个方块全部采样，避免间隔采样漏掉一格厚墙或门洞。高度不超过 384 格时保留每一层，包含地下和室内，不只取最高地表。大范围总览仍会降低水平分辨率；实际 X/Y/Z 采样间距收进「帮助」，降采样或超过展示预算时明确提示，可以聚焦附近或较小矩形提高精度。粗采样块体代表近似地形，不能据此判定一格宽的墙、空洞或未采样处的建筑。

仅对暴露的表面分配地形展示块体，剔除被不透明邻居完全包围的内部方块。连续且方块状态相同的不透明采样点贪心合并，默认合并各轴以 8 格为目标上限；超过 512 个展示块体时，先尝试 16、32 格合并，并仅采用块体数量减少的结果，优先完整保留连续地面、墙面和屋顶，而不是直接删除其中一半。放大合并会使贴图变粗；单个粗采样格也可能超过目标上限。合并不会跨过已采到的空气、未知点或不同方块状态；未采样点不构成精确保证。楼梯、栏杆、铁轨和玻璃等不可合并方块保留原有状态与单块尺寸。

仍超出预算时，以块体中心的实际三维跨度建立自适应空间分区，优先细分跨度最大的区域，各区域保留一个代表块体，而不是固定拿一半预算挑最大面、再按采样序号抽细节。区域内优先保留较大表面，同面积时参考采样邻接的暴露程度及顶部高度，兼顾稀疏街区、塔楼尖顶、屋顶边缘和桥梁端点，避免密集装饰区占满预算。该策略按几何分布抽象，不需要预设住宅、城堡或城市模板；同样适用于曲面分层、地下和多层结构，但不识别建筑语义，也不保证预算极小时每座建筑或每个端点都可见。选择只省略真实采样块体，不新增填充体或跨街道连接，省略时明确提示。粗采样漏掉的窄墙、细桥等不能由抽象阶段恢复，可聚焦较小范围提高精度。边线始终来自真实选区，地形展示不参与保存校验。

立体模型采用 35° 俯仰与等比例缩放，坐标投影和原生显示方块使用一致的轴变换，避免 Z 轴镜像导致楼梯朝向和建筑布局错位。旋转不改变立体缩放比例，最低点贴近底盘。俯视按 X/Z 平面尺寸缩放，并压缩高度在视线方向的厚度，使高楼和地下范围不会把平面图缩成小点；它不用于测量立体高度。

服务端每 tick 全局最多读取 512 点，每位玩家每轮最多 128 点，按队列轮转；剩余预算可以继续分配，不因只有一位玩家而闲置。世界读取与方块状态提取仍在主线程，每 tick 最多提交一份网格快照；表面筛选、体素合并与细节选择在后台执行，后台不调用世界、玩家或 BlockData API。首次扫描从上往下读取，在约四分之一进度提交几何快照，完成后公布百分比；定期更新保留上一份完整模型，直到新扫描和网格构建完成，避免清空闪烁。完整快照完成约 200 tick 后开始下一轮扫描；旋转、俯视切换和玩家标记移动只使用缓存，不重新扫描。关闭或暂停沙盘后停止续期，空闲 30 tick 清理采样缓存；退出服务器或切换线框时取消未完成的网格任务。

实地轮廓和沙盘共享地段不可变单元快照的身份缓存，最多保留 16 份几何。首次打开不在主线程生成边线，也不对全部单元计算缓存键 hash 或 equals；实心长方体只生成 12 条解析边，不规则范围仍保留凹角、洞口与内边线。包围范围、矩形分解及空间边线索引一起在 `mik-plot-preview` 单线程后台完成，待完成时显示准备提示并自动刷新。缓存淘汰取消对应轮廓任务；退出取消该玩家校验与沙盘网格，模块关闭清理全部预览任务。待执行队列有界，满时暂缓提交并在刷新时重试，不无限堆积线程和任务。

每次实地轮廓查询最多取 64 条边；沙盘保存范围、候选范围分别最多取 97、161 条（包括用于判断省略的额外边），空间索引每次最多访问 2048 个节点。裁剪、粒子采样和轮廓比较只处理这批有界结果，不在刷新时遍历完整轮廓。矩形编号查找使用有序列表的二分查找。复杂轮廓被省略时仍显示精度提示；这些预算只影响预览，不限制地段面积、体积或保存单元数。

编辑器相连性、重叠、子地段包含和到访点校验也在后台针对隔离的已提交快照执行，结果按玩家、草稿版本和地段注册表版本缓存。未完成时禁用保存；版本变化取消旧校验，提交保存时仍在数据库工作线程重新验证最新状态。面积统计随保护索引一起生成并发布，打开卡片、详情和列表不再重复扫描全体单元。

沙盘完全由玩家私有显示包组成，不生成真实实体，不改方块，不加载区块。未加载采样以灰色及数量提示；复杂边界最多显示 256 段，超出时明确提示并保留实地选点入口，不能将省略后的边线当成完整校验结果。服务端保存仍经过权限、相连性、重叠、子地段和到访点检查。Bedrock 使用原生表单和实地轮廓，隐藏无法显示的沙盘视角按钮，也不执行无用的地形采样。

## 子地段

从母地段详情或子地段列表直接选择「创建子地段」，选定范围后再次点击「创建子地段」，填写名称和所有者。入口在没有子地段时仍显示，无权限或不在同一世界时禁用。创建使用独立空白草稿，不载入或覆盖母地段编辑草稿，不显示母地段保存按钮。

创建检查母地段的 `create_subplot` 权限，默认所有者和地段管理员具备，可单独授予协作者；`manage_area` 仅控制修改已有范围，两项权限互不代替。子地段不显示、不接受创建子地段权限，也不支持继续嵌套。选区必须位于母地段已保存的单元内且相连，不能与兄弟子地段重叠或覆盖母地段到访点。

预校验在后台使用对应编辑上下文，创建与修改范围不复用校验结果。填写期间选区、编辑意图或母地段状态变化后拒绝旧提交；正式提交仍重新检查当前权限和几何。异步完成只清理已提交的同一份草稿，不清理或跳转其他编辑流程。

子地段使用独立 UUID，可各自设置成员、权限、公告板、到访点、时间与天气。母地段所有者和服务器管理者保留监管权限；普通母地段管理员或协作者不会自动获得子地段建造权。子地段的组权限和环境设置可以跟随母地段，也可独立覆盖。

权限页使用常驻分类栏与「操作／状态」列表：选择所有者、管理员、协作者、服务器新人或正式成员后直接进入表格，左侧切换建造、方块交互、储物、实体或管理分类，不增加返回层级。对象名称可打开选择列表，切换组时保留分类。每行的操作名与状态分列对齐，默认状态显示继承后的允许／禁止结果，来源显示母地段名称、同组和具体规则；游戏状态点击循环切换，管理状态显式选择默认、允许或禁止。管理员和协作者的成员详情均可设置个人权限；地段设置、转让和删除位于独立管理页。可管理对象均可恢复默认，所有者组只允许所有者、母地段所有者和服务器管理者编辑；子地段默认跟随母地段的同组规则；母地段的成员名单和个人设置不自动下放。所有者、管理员与协作者均不绕过细分限制，只有所有者的权限恢复入口、母地段所有者和服务器管理者的监管能力保留保障。各管理操作检查对应能力，不提供受邀访客角色或旧版兼容。成员操作按实际管理能力而非角色标签保护；邀请先编辑未提交草案，再一次提交身份和个人权限。敏感变更先预览已知成员与子地段影响，确认时拒绝过期快照。完整的优先级、授权规则和事件范围见 [地段权限管理](plot-permissions.md)。

修改子地段范围从子地段详情的范围编辑器进行，需对应的范围管理权限，并保留子地段 UUID 和设置。子地段到访点必须留在新范围内。缩小母地段不能把已有子地段移出范围。

删除子地段仅解除划分，原区域回归母地段保护，不删除建筑。删除母地段前必须先处理子地段；提交时重新检查当前权限和层级状态。转让母地段不会改变子地段所有者。
