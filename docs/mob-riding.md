# 生物骑乘

按住 **Shift（潜行）并右键生物**即可骑乘，无需鞍或专用物品。使用主手操作，目标必须存活、没有乘客，且自身未乘坐其他实体；玩家不能处于旁观模式或已经骑乘其他实体。

- **WASD**：按视角方向前进、后退和侧移。
- **空格**：地面跳跃；水中上浮。
- **疾跑键**：加速。
- **Shift**：先松开上骑时按住的 Shift，再按一次下骑。

飞行生物（如恶魂、快乐恶魂、幻翼、蜜蜂、悦灵、恼鬼与凋灵）随视角俯仰升降，空格上升。普通生物保持重力与碰撞，不会因为骑乘而获得飞行能力。

权限 `mik.riding.use` 默认向所有玩家开放。骑乘遵循原有实体交互保护，并额外检查生物所在位置的地段 `ride` 权限；驾驶期间持续复核，失去权限时结束骑乘。玩家、盔甲架与插件载具不属于本功能的生物目标。

他人拥有的已驯服宠物（包括马等可驯服坐骑）禁止通过本功能骑乘或控制，不提供管理员绕过。自己的宠物与无主生物仍可骑乘；骑乘中归属改为他人时，立即结束控制并下骑。归属检查使用主人 UUID，主人离线时同样生效。

骑乘期间暂停生物自主行为，下骑、退出服务器、实体移除或插件关闭后恢复原有状态。生物继续受到环境与伤害影响。
