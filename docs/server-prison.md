# 监狱管理

服务器管理者可以在顶层地段的「地段设置」中启用监狱，通过 `/prison` 或主菜单中的「监狱」查看监狱、当前囚犯、封禁原因和剩余刑期。

## 地段与牢房

- 每个子地段算一间牢房。没有子地段时，整块地段是一间牢房。请在牢房上层留出可站立的空间。
- 玩家入服时，系统根据账号 UUID 哈希选择监狱，再根据账号和监狱 UUID 哈希选择牢房。监狱和牢房按 UUID 排序，改名和重启不会改变分配。增删监狱或牢房可能改变分配。
- 关闭监狱或删除地段前，需要先解除分配到该处的封禁。修改封禁到期时间会更新刑期。

## 准入与保护

- 关押只适用于封禁管理器中的有效本人账号封禁。地址关联封禁、IP 封禁和其他入服检查继续生效。若入服时无法进入牢房，玩家会被断开。
- 囚犯必须留在分配的牢房，不能放置或破坏方块，死亡时保留物品和经验。关押期间可以使用私聊、帮助和规则指令。监狱地段内的放置和破坏还需要地段管理权限。
- 有可用挂点时，囚犯可看到显示封禁原因和剩余刑期的私有墙面面板。永久封禁会显示为永久刑期。
- 解封或封禁到期后，关押限制解除，玩家可以自行离开牢房。

地段数据库保存监狱开关和牢房范围。囚犯名单、原因和刑期实时读取封禁管理器，分配结果随用随算。
