# 监狱管理

服务器管理者可以在顶层地段的「地段设置」中启用监狱，通过 `/ban`（或主菜单中的「封禁管理」）进入「监狱管理」，查看监狱、当前囚犯、封禁原因和剩余刑期。

## 地段与牢房

- 每个子地段算一间牢房。没有子地段时，整块地段是一间牢房。请在牢房上层留出有完整地板和两格净空的位置。
- 系统用账号 UUID 与候选地段 UUID 的哈希分数，先从已加载世界中选监狱，再选牢房。改名或以相同地段重启不改变分配。增加候选只会迁移分到新候选的玩家，删除候选只会迁移原本分到该候选的玩家；第一间子地段会取代原来的整块地段牢房。
- 只要在线囚犯仍有牢房可分配，就可以关闭监狱、删除或调整地段。在线玩家的分配改变时，系统会重新安置；找不到安全落点时断开连接，封禁保持有效。离线玩家在下次连接时重新匹配。

## 准入与保护

- 关押只适用于封禁管理器中的有效本人账号封禁。地址关联封禁、IP 封禁和其他入服检查继续生效。配置阶段会在分配到的牢房上层查找安全落点，最终准入时再次检查牢房和落点。没有可用落点时，玩家按原封禁被拒绝。分到同一牢房的连接共用正在进行的落点搜索，方块检查分批执行。重生也会检查牢房内的落点。
- 在押玩家强制使用冒险模式，只能在分配的牢房内移动和发送游戏内公开文字聊天。聊天仍受原有的认证、限流和内容限制，不进入网页聊天。在押时长不计入治理有效在线时长或活动奖励。
- 关押期间禁用所有命令（含私聊、帮助和规则命令）、飞行、滑翔、骑乘、传送、菜单操作、方块及实体交互、战斗和背包操作。系统可将玩家重新安置到分配的牢房。监狱地段内的放置和破坏还需要地段管理权限。
- 从登录配置阶段起，服务器阻止在押账号注册模组频道，并拦截双向自定义频道消息。游戏登录认证和原生对话框仍可完成。
- 有可用挂点时，囚犯可看到显示封禁原因和剩余刑期的私有墙面面板。永久封禁会显示为永久刑期。
- 解封或封禁到期后，系统恢复入狱前的游戏模式，玩家可以自行离开牢房。正常退出时也会在保存玩家数据前恢复模式；只要封禁仍有效，下次入服就重新应用限制。

地段数据库保存监狱开关和牢房范围。囚犯名单、原因和刑期实时读取封禁管理器，落点和在线分配只在运行期间缓存。
