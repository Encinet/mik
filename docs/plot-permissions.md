# 地段权限

## 使用方式

从 `/plot` → 地段详情 →「权限与成员」选择权限组，或从成员详情打开个人权限。权限表按建造、方块交互、储物与物品、实体、管理五类显示，每行列出操作、有效状态和来源。

- 游戏操作点击切换默认 → 允许 → 禁止 → 默认；管理操作显式选择默认、允许或禁止。
- 「恢复默认」只清除当前对象、当前分类的设置；「恢复默认 · 全部操作」清除当前对象的全部操作设置。环境及未知扩展键保留。
- 所有者通过所有者组配置，不提供个人覆盖或移除。成员名单包含所有者与受邀成员，母地段所有者和服务器管理者的监管身份单独展示。
- 「地段设置与所有权」提供公开标记、转让和删除。公开标记不会自动开放建造或交互。
- Bedrock 使用原生表单，授权与提交规则相同。

命令使用当前组名与操作键：

```text
/plot flag <地段ID> <组.操作> <true|false>
```

组名为 `owner`、`admin`、`collaborator`、`newcomer`、`member`。命令与菜单共用鉴权、管理权限确认和只读约束。

## 操作目录

共 27 项权限：建造 6、方块交互 4、储物与物品 4、实体 6、管理 7。一次操作涉及多种资产时，逐项检查所需权限。

| 分类 | 操作键 | 已接入的主要入口与组合限制 |
| --- | --- | --- |
| 建造 | `place` | 单／多方块放置、普通实体放置、刷怪蛋、船、矿车、末地水晶、桶装生物释放、插件载具生成、编辑器创建普通实体 |
| 建造 | `break` | 方块破坏；带库存方块另需 `container` |
| 建造 | `bucket` | 桶装取液体、炼药锅桶／瓶取放；捕捉生物另需 `animal`，释放生物另需 `place` |
| 建造 | `ignite` | 点火事件、打火石与火焰弹使用；检查目标及相邻作用位置 |
| 建造 | `modify` | 工具改造、骨粉、蜂蜡、耕地踩踏、堆肥、蛋糕、重生锚、花盆取放、炼药锅清洗、末影之眼；施肥／树木生长逐块检查 |
| 建造 | `harvest` | 浆果、洞穴藤蔓、蜂蜜采收及采收事件；剪刀／瓶采蜂蜜不额外要求修改，骨粉施用仍检查修改；破坏普通作物仍按方块破坏判断 |
| 方块交互 | `door` | 门、活板门、栅栏门交互 |
| 方块交互 | `switch` | 按钮、拉杆、压力板、绊线触发；可归因玩家的投射物／实体触发同样检查 |
| 方块交互 | `workstation` | 无独立库存的工作站、床、重生锚使用、铃铛等设施；不替代容器或方块修改授权 |
| 方块交互 | `sign` | 打开编辑、提交文字、染色、发光、封蜡；不因修改方块权限而放行 |
| 储物与物品 | `container` | 方块库存、末影箱、双箱两半、讲台放入／取出书；方块拆除及批量修改需同项保护 |
| 储物与物品 | `entity_storage` | 箱子矿车、马匹等库存、向驴／骡加箱；伤害／移除／拉取／编辑带库存实体同时检查 |
| 储物与物品 | `item_pickup` | 玩家拾取物品、钓竿拉取物品及钓鱼收获，按物品位置判断 |
| 储物与物品 | `item_drop` | 玩家主动丢弃，检查玩家与物品生成位置；不限制死亡和自然掉落 |
| 实体 | `entity_interact` | 普通实体交互、非动物命名、钓竿拉取普通实体、插件载具维护及编辑器修改；有库存另需储物 |
| 实体 | `trade` | 商人交互、交易库存打开；不授权非交易改动 |
| 实体 | `ride` | 乘坐交互、实际挂载及插件载具命令／菜单进入；动物喂食和库存另行判断 |
| 实体 | `animal` | 喂养、剪毛、驯养、动物命名、拴绳、解绳、拴绳结及桶装生物捕捉；拴绳检查动物与锚点 |
| 实体 | `entity_damage` | 非玩家普通实体伤害、原版载具受损／销毁、插件载具移除、编辑器移除／修改；有库存另需储物 |
| 实体 | `decoration` | 画、展示框、盔甲架、展示实体的放置／操作／拆除，展示框放入／旋转／取出物品及插件展示模型采集 |
| 管理 | `manage_settings` | 名称、公开标记、公告板、到访点与文字、时间、天气 |
| 管理 | `manage_area` | 修改当前地段范围，提交时校验相连性、重叠、子地段与到访点 |
| 管理 | `create_subplot` | 在母地段内创建子地段；不适用于子地段，不授予范围修改能力 |
| 管理 | `manage_members` | 成员邀请草案提交、角色调整、移除；涉及实际管理能力另需权限管理 |
| 管理 | `manage_permissions` | 组／个人设置、分类／全部重置及管理授权上限；所有者固定保留恢复入口 |
| 管理 | `transfer` | 所有权转让，与成员角色或设置权限分离 |
| 管理 | `delete` | 地段释放／删除，提交时检查当前权限与子地段约束 |

`create_subplot` 与 `manage_area` 独立。所有者和管理员在母地段默认拥有创建能力；子地段不显示也不接受该权限，不能继续嵌套。

## 优先级与默认值

服务器管理者和子地段的母地段所有者保留监管能力。其余玩家按以下顺序计算权限：

1. 当前地段的个人设置，仅对当前受邀成员有效。
2. 当前地段所属组的设置。
3. 子地段继承母地段同组规则。
4. 角色默认值。

| 身份 | 游戏操作默认值 | 管理能力默认值 |
| --- | --- | --- |
| 所有者 | 全部允许 | 全部允许；`manage_permissions` 固定保留且只读，用于恢复权限 |
| 管理员 | 全部允许 | 设置、范围、创建子地段、成员、权限管理；转让和删除默认禁止 |
| 协作者 | 全部允许 | 全部禁止 |
| 服务器新人、正式成员 | 全部禁止 | 不可授予；管理能力须授予地段成员 |

角色提供默认值，仍受具体设置约束。所有者组只允许地段所有者、母地段所有者和服务器管理者修改。

母地段的成员名单和个人设置不自动继承。子地段先按自己的名单确定玩家所属组，再继承母地段同组规则。例如，母地段协作者未加入子地段时，在子地段按其服务器身份组判断。

移除成员同时删除个人设置，重新邀请不会恢复旧授权。转让会清理新旧所有者的个人设置，旧所有者不会自动成为受邀成员。

## 成员草案与确认

添加成员或执行 `/plot invite` 先创建未提交草案，角色限 `admin`、`collaborator`，可逐分类调整个人权限。切换角色保留个人设置；取消、返回或断开不创建成员。确认后一次发布成员身份和全部个人权限。已有成员切换角色同样保留个人设置。

邀请、角色调整、移除、管理权限修改及重置均预览有效权限变化、受影响的已知成员和子地段继承变化。只改变配置但不改变有效权限时也会标明。预览最多列出六个名称及剩余数量；成员移出后不推测其服务器身份组权限。

提交重新读取当前状态并鉴权：

- 成员变更需要 `manage_members`；目标修改前或修改后具备任一实际管理能力时，还需 `manage_permissions`，不按角色名称判断。
- 不能给自己或他人新增自己不具备的管理能力，显式固化已有允许、邀请、角色调整和恢复默认也接受同样检查。在可管理对象范围内，可以撤销自己不具备的能力。
- 预览关联的当前地段、母地段或相关子地段状态改变后，旧确认失效，须重新预览。无关地段变化不阻止提交。

## 编辑器与环境保护

FastAsyncWorldEdit、Axiom 和已接入的原版修改命令使用统一查询。内部 `build` 查询汇总建造分类、告示牌和容器权限，不是一项可配置权限，也不要求物品拾取或丢弃权限。编辑器创建装饰实体检查 `decoration`，拴绳结检查 `animal`，普通实体检查 `place`；修改普通实体需交互与伤害权限，移除需伤害权限，带库存时另需实体储物权限。

FastAsyncWorldEdit 的批量编辑通过原生队列处理器检查方块、生物群系、方块实体与实体放置；绕过历史记录的写入也经过检查。世界与玩家组权限在主线程读取，异步处理器查询地段的不可变权限快照。未使用区块队列的编辑通过逐项写入检查，无需手动配置 FAWE 的扩展允许列表。

插件载具按操作检查：生成用 `place`，进入用 `ride`，维护用 `entity_interact`，移除用 `entity_damage`，展示模型采集用 `decoration`。

火焰烧毁、爆炸、实体改块、液体和活塞跨界使用独立的环境保护。漏斗等自动库存移动及自动拾取检查两端实际位置（包括双箱两半），禁止跨不同地段、母子地段或地段与外部边界；同一地段内部和完全外部允许转移。

地段权限不改变 PvP、移动、进入或玩家自身背包规则；无世界位置的虚拟库存和绕过事件及集成接口直接修改世界的其他插件不在覆盖范围内。

权限修改校验通过后立即生效，后台按顺序持久化。失败处理与备份见[地段数据](plot-board.md#保存与数据)。
