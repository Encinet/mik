# 正版认证容灾

服务器直接运行 `online-mode=true` 时自动启用，无命令或配置文件。正常登录始终先调用 Minecraft 原有认证服务；仅在服务报告不可用时，允许近期认证成功、来源 IP 相同的玩家使用缓存身份连接。

此模块处理服务器端会话检查。启动器登录或客户端提交入服请求失败时，仍需等待相应服务恢复。

## 身份与准入

- 正常认证直接使用官方返回的 UUID；回退使用原先缓存的同一 UUID、签名皮肤属性与账号限制信息，不生成离线 UUID。恢复官方认证后继续使用官方结果。
- 缓存按玩家名查找，同时核对来源 IP。名字大小写不影响查找；只有最近一次官方认证成功的 IP 有效，IPv4 与 IPv6 都按地址字节比较。
- 缓存自最后一次官方认证成功起有效 **72 小时**。回退登录不续期，重启也不重置认证时间。未知玩家、IP 不同、缓存过期或时间倒退至认证时间之前时，保留原来的认证失败结果。
- 官方正常拒绝登录时不会回退。每次连接都先尝试官方认证，服务恢复后自动恢复正常路径。
- 官方确认玩家改名时保留其 UUID，同时移除旧名字的缓存绑定。故障期间无法确认的新名字需要等待官方认证恢复。

缓存身份仍然进入现有封禁、白名单、维护模式和[密码验证](account-security.md)流程。已有密码的玩家照常验证，管理账号照常强制设密。

同一公网 IP 可能由多个玩家共用，因此 IP 匹配不能替代玩家持有正版凭据的密码学证明。容灾放行依赖上次官方认证与相同地址；需要额外保护的账号应设置本服密码。

## Geyser 与 Floodgate

Geyser 的 `online` 模式到达 Paper 的会话认证阶段后可使用相同的缓存规则，保留原 Java 正版 UUID；没有可核对的来源 IP 时拒绝回退。本模块无法接管 Geyser 在此之前执行的微软登录或客户端入服请求，也不处理 Xbox 认证故障。

Geyser + Floodgate 保留其原有登录链路。Floodgate 在校验自身握手数据后直接提供玩家资料，不经过这里包装的 Java 会话认证方法，因此不会把基岩 UUID 改成 Java 离线 UUID，也不会覆盖已绑定 Java 账号的 UUID。相关身份与绑定规则由 [Floodgate](https://geysermc.org/wiki/floodgate/) 负责；此处提供共存兼容，不为 Floodgate 建立另一份回退身份。

## 存储与生命周期

缓存保存于 `plugins/mik/auth-fallback.db`，最多保留最近认证的 **10,000** 名玩家。写入会清除过期记录并淘汰最早认证的记录；数据库保存 UUID、名字、IP、官方资料与认证时间，不保存客户端令牌。支持 POSIX 权限的系统将数据库权限设为仅所属用户读写。

文件加载和关闭由模块后台线程处理，登录中的网络和数据库操作运行在 Paper 原有认证线程上。数据库损坏或写入失败会停止使用缓存，官方认证继续工作；损坏数据不会被空缓存覆盖。修复或从备份恢复数据库后正常重启服务器。

模块包装当前 Paper 26.3 的认证服务，不新增 HTTP 监听端口。为获取连接地址，会在运行期间启用 `prevent-proxy-connections` 的地址传递，向官方认证服务发送 IP 的策略仍遵循服务器原有设置。模块不修改 `server.properties`，停用时恢复原服务与原设置，关闭缓存和后台线程。

离线模式、BungeeCord、Velocity 或 PROXY protocol 转发环境自动跳过；认证由代理完成时，应在代理侧提供容灾。接入接受 Mojang 原始认证服务与 Paper 自带的 `PaperMinecraftSessionService`；遇到其他实现时停止接入并记录实际类型，避免叠加不同的认证规则。启用、跳过、回退使用和缓存故障均记录到控制台。

## 排查

启动时应出现 `Authentication fallback enabled`。若出现 `Could not enable authentication fallback`，模块未启用，后续认证故障仍会由 Paper 原样断开连接。旧版本曾将 Paper 自带的认证服务误判为其他插件替换，报出 `Another plugin already replaced the session service`；更新插件并正常重启服务器。

模块启用后，需要先完成一次成功的官方认证，才能为该玩家建立缓存。仅在安装插件前登录过、一直保持在线或当前官方认证已经不可用时，不能据此补建已验证身份。

此适配依赖 Paper 26.3 的内部服务结构；升级 Paper 后应在测试服检查实际正版登录、故障回退与停服恢复。
