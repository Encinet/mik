# 地段权限分类与覆盖清单

## 分类原则

目录共五类、26 项权限：建造 6、方块交互 4、储物与物品 4、实体 6、管理 6。每项仅归属一个分类，菜单、个人设置、组设置、继承、重置、邀请草案和预览使用同一目录。分类集合为不可变缓存，测试校验唯一键、完整分区及每类不超过六项。

按玩家操作意图和资产风险划分，不按角色划分；组合操作逐项鉴权，不通过一个大类权限隐式授权另一个操作。`build` 仅是编辑器内部的保守聚合查询，不出现在可配置目录中。物品拾取／丢弃不影响批量建造授权。

| --- | --- | --- |

| 建造 | `modify` | 工具改造、骨粉、蜂蜡、耕地踩踏、堆肥、蛋糕、重生锚、花盆取放、炼药锅清洗、末影之眼；施肥／树木生长逐块检查 |
| 建造 | `harvest` | 浆果、洞穴藤蔓、蜂蜜采收及采收事件；剪刀／瓶采蜂蜜不额外要求修改，骨粉施用仍检查修改；破坏普通作物仍按方块破坏判断 |

| 方块交互 | `sign` | 打开编辑、提交文字、染色、发光、封蜡；不因修改方块权限而放行 |
| 储物与物品 | `container` | 方块库存、末影箱、双箱两半、讲台放入／取出书；方块拆除及批量修改需同项保护 |
| 储物与物品 | `entity_storage` | 箱子矿车、马匹等库存、向驴／骡加箱；伤害／移除／拉取／编辑带库存实体同时检查 |
| 储物与物品 | `item_pickup` | 玩家拾取物品、钓竿拉取物品及钓鱼收获，按物品位置判断 |
| 储物与物品 | `item_drop` | 玩家主动丢弃，检查玩家与物品生成位置；不限制死亡和自然掉落 |
| 实体 | `entity_interact` | 普通实体交互、非动物命名、钓竿拉取普通实体、插件载具维护及编辑器修改；有库存另需储物 |
| 实体 | `trade` | 商人交互、交易库存打开；不授权非交易改动 |
| 实体 | `ride` | 乘坐交互、实际挂载及插件载具命令／菜单进入；动物喂食和库存另行判断 |
| 实体 | `animal` | 喂养、剪毛、驯养、动物命名、拴绳、解绳、拴绳结及桶装生物捕捉；拴绳检查动物与锚点 |
| 实体 | `entity_damage` | 非玩家普通实体伤害、原版载具受损／销毁、插件载具移除、编辑器移除／修改；有库存另需储物 |
| 实体 | `decoration` | 画、展示框、盔甲架、展示实体的放置／操作／拆除，展示框放入／旋转／取出物品及插件展示模型采集 |
| 管理 | `manage_settings` | 名称、公开标记、公告板、到访点与文字、时间、天气 |
| 管理 | `manage_area` | 地段范围修改、创建子地段、修改子地段范围及几何约束校验 |
| 管理 | `manage_members` | 成员邀请草案提交、角色调整、移除；涉及实际管理能力另需权限管理 |
| 管理 | `manage_permissions` | 组／个人设置、分类／全部重置及管理授权上限；所有者固定保留恢复入口 |

| 管理 | `delete` | 地段释放／删除，提交时检查当前权限与子地段约束 |

## 非成员授权规则

环境保护独立于玩家目录：火焰烧毁、爆炸方块列表、实体改块、液体及活塞跨界沿用环境约束。自动库存移动和自动拾取逐位置检查边界，包括双箱两半以及母子地段；同地段内部和完全外部仍可自动化。这些事件没有可靠的玩家操作者，不能伪造为某个成员的拾取／储物授权。

不是所有游戏行为都应成为地段授权：不新增移动／进入限制，不调整 PvP，不管理玩家自身背包，不把自然掉落和自然环境绑定到成员角色。无位置的虚拟库存、其他生物自动拾取和绕过事件直接写世界的插件不由玩家权限保证覆盖。

## 回归约束

- `PlotGranularAccessTest`：目录唯一性、分类完整性、默认值与个人覆盖、聚合建造规则。
- `PlotInteractionActionsTest`：物品／方块／实体意图区分、马匹及装饰、拴绳结、编辑器实体分类。
- `PlotProtectionPermissionsTest`：放置与破坏、容器拆除、门与开关、乘坐与投射物伤害。
- `PlotProtectionCoverageTest`：拾取／丢弃边界、桶装生物、原版与插件载具、驯养／拴绳、钓竿、花盆、讲台、展示框、炼药锅、床、告示牌及自动库存边界。
- 权限计划与管理测试：统一鉴权、原子提交、授权上限、成员保护、继承影响、过期确认与伪造计划拒绝。
- 16 种语言资源和权限表测量测试：所有分类、草案、状态及不同文字尺寸均可正常呈现。

不增加审计、历史、迁移或旧版兼容路径。实际游戏客户端、其他插件和服务器事件顺序仍应在部署环境做集成验收。
