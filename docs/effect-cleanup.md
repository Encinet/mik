# 负面效果清除

玩家在创造或旁观模式、未处于 PVP 战斗时，获得负面药水效果后会收到聊天提醒，说明效果来源并提供清除按钮。

- **清除负面效果**：移除当前的负面效果，保留增益与中性效果。
- **清除全部效果**：移除当前全部药水效果；只有同时存在增益或中性效果时才显示。

战斗状态复用 PVP 功能的实际伤害标记：确认发生玩家间伤害后持续 15 秒，继续造成伤害会刷新。仅开启 PVP 开关不会阻止此提醒。

提醒在效果事件结束后复核，已取消、未覆盖旧效果或已经消失的效果不触发。同一 tick 获得的负面效果合并展示来源；来源由服务器事件提供，无法识别时显示未知来源。负面效果按服务器的效果分类判定，中性效果不会触发提醒。

按钮请求有效期为 1 分钟，只能由收到提醒的玩家使用，两个按钮共用一次清除机会。有效期内重复施加相同效果和来源不会重复提醒；效果种类或来源变化会更新提醒，并使旧按钮失效。点击时会重新检查游戏模式、实际战斗状态与当前效果，退出或功能停用也会使请求失效。

此提醒属于当前效果的操作请求，不受[场景提示](guidance.md)的教程冷却限制。
