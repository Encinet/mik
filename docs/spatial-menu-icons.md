# 空间菜单图标规范

图标是普通内容：`UiIcon` 定义图形，`Ui.button(icon, label)` 绑定动作，`Ui.icon(icon, label)` 表达只读状态。调用见 [API](spatial-menu-api.md#平面图标)，整体边界见[菜单架构](spatial-menu-design.md)。

## 样式与布局

- 基础图形使用统一平面线形：24×24 逻辑画布、基准线宽 2、主要笔画位于 2–22 范围。圆弧分段、接缝与光学校正由图形定义处理。
- 默认图形为 16×16 UI，图标按钮与单行文字按钮共用 21 UI 最小高度；只读图标保留图形占位。二者共同继承字号，行与表格负责对齐。
- 图形尺寸、点击留白和动画包络分别维护。标签、语言和帧切换不改变占位，调用方不补世界坐标或手填笔画位置。
- 图标使用主题语义色；关闭、取消和清除通常为中性操作。状态同时有形状或文字说明，不能只靠颜色或是否运动区分。
- 可用图标与背景的对比度目标为 3:1，普通文字为 4.5:1；复杂世界背景仍需实测。参见 [非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)与[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 图标目录与含义

目录对应 `UiIcons` 的 32 个图形。同一形状维护一份定义，动作差异由名称、对象和回调表达。

| 图形 | 用途 | 易混淆的边界 |
| --- | --- | --- |
| `CROSS` | 关闭、取消输入、清除局部值 | 标签说明作用对象，不代替删除集合 |
| `CHEVRON_LEFT` / `CHEVRON_RIGHT` | 返回、进入或前后页 | 宿主明确一种含义，与媒体切歌区分 |
| `CHEVRON_UP` / `CHEVRON_DOWN` | 折叠、展开 | 不表示排序或移动条目 |
| `ADD` | 加入、新建 | 说明加入何处；复杂新建保留文字 |
| `REMOVE` | 从列表或组中移出 | 与彻底删除区分 |
| `CHECK` | 确认、成功 | 选择用复选框，播放用活动状态 |
| `REFRESH` | 刷新、重试 | 标签区分两者，不表示循环播放或撤销 |
| `UNDO` | 撤销编辑 | 不代替返回、刷新或恢复默认 |
| `COPY` | 复制信息或对象 | 区分剪贴板、样式与新副本 |
| `EXTERNAL_LINK` | 站外内容 | 保留目的地名称 |
| `MORE` | 次级操作 | 高频动作保留直接入口 |
| `SEARCH` | 搜索入口 | 搜索框已有占位说明时可省略 |
| `SETTINGS` | 设置或参数 | 保留具体项目名称 |
| `DELETE` | 删除对象 | 保留对象和后果，沿用业务确认策略 |
| `INSERT_BEFORE` | 放到条目前 | 仅用于已进入的放置步骤 |
| `BOX` / `CHECKED_BOX` | 未选择、已选择 | 绑定条目身份，与指向和成功状态分开 |
| `INFO` | 补充说明 | 只读状态与打开详情是两种用途 |
| `WARNING` | 限制或部分结果 | 伴随原因 |
| `ERROR` | 操作失败 | 重试另有明确动作 |
| `LOADING` | 任务进行中 | 由真实任务驱动，无比例时不显示百分比 |
| `ACTIVITY_BARS` | 正在输出音频 | 活动提示，不是频谱；暂停改为静态暂停形状 |
| `PLAY` / `PAUSE` | 开始或继续、暂停 | 表示点击后的动作 |
| `PREVIOUS` / `NEXT` | 上一首、下一首 | 上一首的从头规则归播放功能 |
| `STOP` | 停止输出 | 与清空队列分开 |
| `VOLUME` / `MUTE` | 音量、静音 | 标签区分组音量、单台音量及当前状态 |
| `QUEUE` | 播放队列 | 与来源歌单目录区分 |

播放模式、排序、权限和同步组来源等需要比较选项的内容使用文字。

## 标签、动作与作用域

交互图标使用本地化动作名称，如「关闭此浮窗」「取消输入」「清除搜索」「重试输出」。只读图标描述当前事实；禁用原因优先于普通帮助。已有文字按钮仅在有补充信息时显示 Tooltip，图标按钮使用语义名称；提示规则见 [API](spatial-menu-api.md#提示工具条与动态偏好)。

| 位置 | 叉号的含义 |
| --- | --- |
| Popover 标题 | 关闭当前浮窗及其输入，保留父页 |
| 正在编辑的搜索 | 取消本次输入，保留已提交查询 |
| 已提交且非空的搜索 | 清除查询；空白未编辑时无叉号 |
| 表单字段 | 清空该字段草稿，不保存或关闭整个表单 |

宿主统一生成 Popover 标题和关闭。刷新由功能提供，保留原位置，不覆盖草稿；已关闭实例的响应和旧关闭动作失效。关闭与取消若有不同后果，应保留不同名称和入口。

```java
Ui.button(UiIcons.REFRESH, refreshLabel)
        .key("refresh").primary(refreshCommand).build();
Ui.icon(UiIcons.ACTIVITY_BARS, playingLabel)
        .key("playback-status")
        .tint(UiColor.themed(UiColorRole.MUSIC_ACCENT)).build();
```

## 绘制与动画预算

图形由固定矩形笔画绘制，每根使用主体与边缘两层过渡；这属于几何平滑，客户端并未提供通用 SVG 或硬件抗锯齿接口。图标不依赖字体字符、网络图片或资源包。

- 每图形最多 16 根笔画、32 个展示部件；最多 32 帧，各帧部件数一致。
- 动画复用实体身份和会话时钟，不逐帧创建实体或重新排版。每会话至多一个持续状态动画，优先浮窗、再优先加载提示，按 10 Hz 推进。
- 减弱动态使用静态帧，仍区分播放、暂停和加载。普通按钮按压不启动循环任务。
- 部件计入[场景预算](spatial-menu-api.md#预算)，随挂起、关闭、换世界、退出和功能停用清理。

音乐从播放快照选择状态图形和动作：播放为音柱与暂停键，暂停为静态暂停状态与继续键，准备为加载状态与当前准备任务的取消。业务执行时核对目标、播放及准备批次；共享图标不查询设备或管理加载状态。详细行为见[音乐手册](music.md#播放与队列)。

扩充图形时同步 `UiIcons`、本目录、参考 SVG 与测试；记录实际用途、易混淆动作、绘制框、部件上限和静态替代。低频高影响操作保留必要文字。
