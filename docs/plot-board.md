# 地段与公示板

## 日常操作

1. `/plot` 打开地段菜单，选择「建立地段」、框选范围并填写名称。正式成员可以直接建立地段。
2. 地段详情提供范围编辑、权限与成员、改名、公告板、到访点和删除；组合形状和子地段操作见[选区与子地段](plot-subplots.md)。
3. 删除只解除登记和保护，保留建筑；删除母地段前须先处理子地段。

范围向外对齐 4×4×4 网格，必须相连且不能与其他地段的有效保护范围重叠，不设面积、体积或单元数量配额。保存后边界固定，普通建造和 WorldEdit 不会自动扩张保护。

## 范围编辑

| 操作 | 用法 |
| --- | --- |
| 标记当前位置 | `//pos1`、`//pos2` |
| 指定坐标 | `//pos1 x,y,z`、`//pos2 x,y,z` |
| 实地选点 | 木斧左键选点 1、右键选点 2 |
| 返回编辑面板 | 潜行＋交换副手（默认 F），或 `/plot edit` |
| 编辑指定地段 | `/plot edit <地段ID前缀>` |
| 结束会话 | `/plot edit stop` |

两条标点命令只在地段编辑会话内接管，不修改 WorldEdit 选区；会话外仍交给 WorldEdit。木斧以外的工具和空手可以正常使用。

青色边线表示已保存范围，绿色与金色标记角点，紫色表示待保存网格边界。菜单收起后仍可走动选点。20 分钟没有移动或操作、换世界、死亡、失去权限、目标删除或离线会结束会话。

编辑已有地段会载入已保存范围；完整两点可直接替换范围，只有一点时不能提交。每人最多保留 8 份草稿，单份撤销与重做合计最多 16 步。提交重新校验权限、相连性、重叠、子地段和到访点；旧确认不会覆盖后来修改的范围或清除新草稿。

## 地段公告板

正文最多 4096 个 Unicode 字符，换行计入总长度，emoji 等补充平面字符按一个字符计算。允许多行，统一换行符并去除首尾空白，禁止其他控制字符；留空清除公告。

所有玩家都可阅读，编辑需要 `manage_settings`。菜单显示摘要，「查看全文」打开只读分页页，分页不会截断保存内容。公告修改后刷新，清空或删除地段后退出阅读页。

社区公示通过 `/plot board` 查看，与地段自己的公告板独立。

## 保存与数据

成员、权限、改名、公告、环境和到访点经最新状态校验后立即在内存生效。创建、修改范围和删除先在后台准备几何与索引，提交前再次检查状态版本；失败保留旧保护和草稿。

数据库按受理顺序逐笔事务写入，失败时记录日志并重试，不回退已生效的内存状态。正常停服最多等待 30 秒排空已受理写入；持续存储故障或突发崩溃可能丢失未落盘修改，应检查服务器日志。

| 路径（相对 `plugins/mik/`） | 内容 |
| --- | --- |
| `plots/plots.db` | 地段、成员、权限和设置 |
| `plots/board.db` | 社区公示 |
| `plots/board-alerts.yml` | 公示通知状态 |

正常停服后备份整个 `plots/` 目录，包括 SQLite 的 WAL、SHM 文件。插件只读取当前目录与数据结构，不自动迁移根目录下的旧数据库。
