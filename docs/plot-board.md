# 地段与公告板

## 日常操作

1. `/plot` 打开地段菜单，选择「建立地段」、框选范围并填写名称。正式成员可以直接建立地段。

2. 地段工作区提供范围编辑、成员与权限、改名、公告板、传送点和删除；组合形状和子地段操作见[选区与子地段](plot-subplots.md)。
3. 删除只解除登记和保护，保留建筑；删除母地段前须先处理子地段。

地段列表将「当前位置」保留为独立快捷入口，列表按「我拥有的」和「我参与的」切换；所有者不会重复出现在参与列表中。列表分页展示，支持按名字片段或编号前缀搜索，支持带 `#` 的编号。切换分类保留搜索词并回到第一页；进入详情再返回保留分类、搜索和页码。没有匹配结果时可修改或清除搜索。创建、管理员的按玩家查找和帮助分别放在固定的操作区。

地段、管理员目录、子地段及成员根据当前字号和可读空间确定列数与每页容量。卡片在窄处收紧，名称与摘要保留提示，点击仍打开同一对象；列表页不再固定显示六或八项。工作区概况可逐页阅读，成员目录与权限组保持独立，设置中的所有权操作保留分组。

帮助页按可读空间逐段展示操作说明，翻页和语言变化保留所在段落。关闭帮助不影响已有选区或编辑草稿。

点击地段进入工作区，先显示名称、所有者、规模、当前身份和公告，再按实际能力提供「传送点」「范围编辑」「子地段」「成员与权限」「设置」任务入口。传送点只在有可用点或具备管理能力时显示；子地段入口只在母地段存在子地段或可创建时显示。各项管理入口分别检查自己的权限，拥有一种管理能力不会显示其他无关操作。编号仅在设置中展示，日常列表不反复显示内部编号。

「成员与权限」在同一页展示成员列表和权限组，添加成员位于成员列表旁；点击成员查看其角色与个人权限，点击权限组进入分类权限表。权限表始终显示所属地段、编辑对象、操作类别和状态来源。「设置」集中提供改名、地段公告与环境，所有权转让和删除放在独立分组。传送点与子地段各自维护独立任务页，不在设置中重复放置入口。

环境页分别浏览时间和天气，两个区域各自保留页码与选中值。切换区域或翻页只改变阅读位置，点击具体选项才修改设置。自定义时间使用 `HH:mm`；格式不正确时保留输入并显示原因，提交前再次检查当前地段和管理权限。离开后，旧输入回调不会重新打开环境页。

按玩家管理地段、成员邀请与转让均先展示玩家搜索结果，点击选定对象后才进入对应操作；转让和删除继续保留确认。删除成功后才离开当前页面，失败保留原页面；若等待期间已转到其他页面，不强制跳转。成员头像使用平面玩家头像。

范围向外对齐 4×4×4 网格，必须相连且不能与其他地段的有效保护范围重叠，不设面积、体积或单元数量配额。保存后边界固定，普通建造和 FastAsyncWorldEdit 不会自动扩张保护。

## 传送点

每个地段可添加多个传送点，子地段各自管理。进入地段工作区的「传送点」，站在地段内安全的地面上选择「添加当前位置」，填写名字和可选介绍。名字为单行、最多 48 个 Unicode 字符，介绍可换行、最多 512 个 Unicode 字符；文字按原样显示。位置包含坐标和朝向，创建时默认不公开。

有 `manage_settings` 权限的成员可以改名、修改介绍、设置传送标题、更新位置、切换公开状态和删除；删除前确认目标。非公开点供地段所有者、受邀成员及已有监管身份使用。修改地段范围须保留全部传送点，创建或扩大子地段不能覆盖母地段传送点；遇到冲突须先移动或删除相应传送点。

管理页的「传送标题」逐字段浏览和编辑标题、副标题，支持 MiniMessage 颜色、装饰、渐变与彩虹，例如 `<gold>欢迎来到庭院</gold>`。标题显示文字最多 32 个 Unicode 字符，副标题最多 64 个，每项原文最多 512 个字符，均为单行。编辑页展示格式效果；「全屏预览」显示实际游戏标题，中央区域让空，返回后保留草稿。编辑和预览均不保存，只有「保存标题」提交。单项留空则不显示该项，两项都空则不弹出标题；传送成功且实际到达对应落点后才展示，失败或被其他插件重定向时不展示。

主菜单的「传送点」打开分页弹窗，列出公开点的名字及所属地段，提示提供介绍预览；条目旁的信息按钮打开完整介绍阅读页，翻页后仍可传送。点击点名直接传送；多个点分别展示。地段工作区也可打开自己能使用的传送点列表，点击条目直接传送；管理者使用条目旁的「管理」编辑设置，详情中的长介绍完整分页。列表容量随可读空间变化，关闭或更新后的旧操作失效。传送先异步加载目标区块，再在主线程复核最新点位、权限、有效所属地段和落点安全；点位变更、删除、关闭公开或失去成员资格会使对应旧请求失效。新的请求取代尚未完成的旧请求，离线和功能关闭后不再执行。

当前数据库中的旧到访点由独立迁移步骤一次转换为传送点：使用地段名作为名字，原主副标题转为纯文本介绍，并保留格式原文为对应传送标题，公开状态沿用原地段标记，保留位置和朝向。已有传送点表自动补齐标题和副标题，初始留空。迁移事务成功后删除旧到访表和地段公开字段；新功能只读写新结构，重启不会重复生成传送点。

## 范围编辑

| 操作 | 用法 |
| --- | --- |
| 标记当前位置 | `//pos1`、`//pos2` |
| 指定坐标 | `//pos1 x,y,z`、`//pos2 x,y,z` |
| 实地选点 | 木斧左键选点 1、右键选点 2 |
| 返回编辑面板 | 潜行＋交换副手（默认 F），或 `/plot edit` |
| 编辑指定地段 | `/plot edit <地段ID前缀>` |
| 结束会话 | `/plot edit stop` |

两条标点命令只在地段编辑会话内接管，不修改 FastAsyncWorldEdit 选区；会话外仍交给 FastAsyncWorldEdit。木斧以外的工具和空手可以正常使用。

青色边线表示已保存范围，绿色与金色标记角点，紫色表示待保存网格边界。菜单收起后仍可走动选点。20 分钟没有移动或操作、换世界、死亡、失去权限、目标删除或离线会结束会话。

编辑已有地段会载入已保存范围；完整两点可直接替换范围，只有一点时不能提交。每人最多保留 8 份草稿，单份撤销与重做合计最多 16 步。提交重新校验权限、相连性、重叠、子地段和传送点；旧确认不会覆盖后来修改的范围或清除新草稿。

## 地段公告板

在地段工作区的设置中选择「编辑地段公告板」，会直接打开带有现有全文的多行 Dialog。可以修改已有文字、补充段落或整段粘贴；「完成」返回空间预览，再确认保存。再次编辑带入最新草稿；Dialog 取消或 Escape 保留打开前的值，表单取消不修改公告。正文校验失败或权限失效时保留草稿并提示原因，编辑不设超时。

正文最多 4096 个 Unicode 字符，换行计入总长度，emoji 等补充平面字符按一个字符计算。允许多行，统一换行符并去除首尾空白，禁止其他控制字符；留空清除公告。

所有玩家都可阅读，编辑需要 `manage_settings`。主菜单在右侧显示当前地段公告，以地段名称作为卡片唯一标题，正文保留换行并优先完整展开；整页放不下时才显示最多八行摘要，保留悬浮全文并提供「查看全文」。没有公告时不显示卡片。点击全文入口在浮窗阅读，与地段独立公告页共用内容、样式和分页。公告修改后刷新；切换到其他地段、清空公告或删除地段后，原卡片的浮窗关闭。独立阅读页在清空或删除后退出，分页不会截断保存内容。

## 保存与数据

成员、权限、改名、公告、环境和传送点经最新状态校验后立即在内存生效。创建、修改范围和删除先在后台准备几何与索引，提交前再次检查状态版本；失败保留旧保护和草稿。

数据库按受理顺序逐笔事务写入，失败时记录日志并重试，不回退已生效的内存状态。正常停服最多等待 30 秒排空已受理写入；持续存储故障或突发崩溃可能丢失未落盘修改，应检查服务器日志。

| 路径（相对 `plugins/mik/`） | 内容 |
| --- | --- |
| `plots/plots.db` | 地段、成员、权限和设置 |

正常停服后备份整个 `plots/` 目录，包括 SQLite 的 WAL、SHM 文件。插件只读取当前目录与数据结构，不自动迁移根目录下的旧数据库。
