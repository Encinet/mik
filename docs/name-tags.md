# 名牌

入口：`/nametag`，也可从主菜单设置的名称标签分类进入。界面展示 LuckPerms 前后缀效果；不修改原版头顶名字。

「我的名牌」位于上方，「玩家样式」位于下方，两块区域自动对齐宽度。目录按编辑区之外的可用高度分页，保存、取消与返回操作位于底部。

## 编辑与预览

1. 「我的名牌」把当前前缀和后缀效果直接显示在各自的输入框内；点击输入框后，在聊天框发送 MiniMessage 原文即可编辑。
2. 每条有效消息替换当前字段预览，完整名牌预览同步更新；错误保留上次有效预览并显示原因。
3. 点击常驻工具区的确定保存，取消放弃本轮草稿。清空也先预览，再确定。

同时只编辑一个字段，另一字段的修改暂时禁用，其效果持续显示；确认和取消继续作用于原草稿。每项最多 200 个 Unicode 码点，保留前后空格；格式和变量会验证。预览读取已发送的消息，不读取聊天框尚未发送的按键。

编辑消息不进入公共聊天、私聊、管理频道、延迟发送或外部转发，普通命令仍可使用。聊天接收无超时，确定、取消、离开、关闭、换世界或退出后停止；未确认内容不保存。返回后再次点击输入框即可继续编辑。

当前效果和编辑初值读取 LuckPerms 实际生效元数据，包含继承、上下文及堆叠。清空只移除本功能拥有的自定义节点，继承或其他来源的效果仍可能显示。

玩家名颜色读取 LuckPerms `username-color` 元数据，如 `<yellow>`、`<white>` 或 `<#55AAFF>`；不按权限组名硬编码。缺失或无效时使用白色。颜色与前后缀一起进入身份快照，游戏聊天、Tablist 和已绑定外部发言共用；编辑或复制前后缀不会更改该颜色。

## 查看与复制

玩家样式目录包含设置了个人前后缀的在线与离线玩家，卡片只显示样式。按实际宽度横排换行，每页最多三行；少量结果收缩，多页保持最大实际页面的阅读区域。滚轮和前后页按钮共用页码，首末页停止。

点击卡片会将前缀、后缀原文分别发送到自己的聊天框，非空字段带复制按钮。复制不直接应用，也不改变当前草稿；使用时进入自己的对应字段，粘贴、发送、预览后确定。MiniMessage 标签、变量和空格保留，角色权限、平台标记与玩家名不随样式复制。

目录只使用个人直接持有的永久、正值、无上下文节点，同字段取最高优先级，同优先级稳定选择；继承角色、临时和特定世界设置不作为可移植样式。当前对查看者不可见的在线玩家不列出。目录按姓名与 UUID 稳定排序，以 UUID 绑定操作。

## 保存与维护

保存前复核正式成员及以上资格和字段版本，只修改本功能优先级下的个人永久、正值、无上下文节点。外部修改或保存失败保留草稿，显示当前效果和原因，再次确认才替换。提交期间阻止重复保存；已提交操作可能在页面关闭后完成，但结果不重开页面。

功能位于 `feature/player/profile/nametag/`：[渲染](../src/main/java/org/encinet/mik/feature/player/profile/PlayerNameTagRenderer.java)、[目录](../src/main/java/org/encinet/mik/feature/player/profile/nametag/NameTagDirectory.java)、[保存](../src/main/java/org/encinet/mik/feature/player/profile/nametag/NameTagStore.java)。目录异步查询 LuckPerms 索引，共享缓存与在途请求，不扫描离线玩家存档；关闭取消请求并使迟到结果失效。

菜单组合与输入清理遵循[空间菜单架构](spatial-menu-design.md)。
