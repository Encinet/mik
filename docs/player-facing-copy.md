# 玩家界面文案清理

## 检查范围与标准

本轮按语言资源与实际调用检查整个插件的玩家侧文案，重点核查主菜单、语言与界面设置、公告、音乐、治理、载具、家、聊天、提及、传送、玩家对战、封禁、活动、世界重生成、身份绑定和外部平台帮助。地段界面沿用上一轮清理结果。

只删除不提供额外信息的重复操作说明、装饰尾行、错误的空状态引导，以及没有调用的旧提示资源。状态、操作对象、权限来源、失败原因、输入约束、非直观快捷键和风险后果不按字数长短判断是否删除。检查基于代码与测试，不等同于游戏客户端视觉验收，也不保证不存在其他上下文相关的冗余。

## 本轮具体改动

| 位置 | 原文或问题 | 处理 |
| --- | --- | --- |
| 公告聊天入口 | 「查看全部公告」后再附「（点击）」，悬停又显示「打开公告菜单」 | 删除后两项；保留下划线链接及打开操作 |
| 外链对话框 | 「返回主菜单」按钮的提示再次写「回到主菜单」 | 删除重复提示；返回按钮保留 |
| 音乐加载 | 「正在加载」下再次写「请稍候，正在读取可用内容」 | 只保留加载状态；请求错误及恢复建议保留 |
| 唱片物品说明 | 末尾空行加「♪ 音乐唱片 ♪」 | 删除装饰尾行；曲名、作者、时长、操作说明和签名保留 |
| 空播放队列 | 「播放队列为空」下说明「使用‘选择音乐’添加歌曲」 | 删除说明，在空队列页直接提供「选择音乐」按钮 |
| 队列摘要 | 页码后附「每页最多 16 首」 | 保留页码及队列数量，删除固定分页容量说明；实际仍每页 16 首 |
| 治理联署 | 「选择联署支持，或填写管理名字发起」重复页面上的联署项、新建按钮及输入框 | 删除常驻说明与对应布局区域；资格校验、人数和确认保留 |
| 治理首页、历史 | 没有投票时仍显示「选择一项投票查看详情」 | 删除无法执行的提示；已有「暂无」空状态保留，有投票仍默认展示详情 |
| 载具网格吸附 | 状态后重复「（点击切换）」 | 只保留「网格吸附：开启／关闭」；切换操作不变 |
| 载具预览提示 | 列出所有可见标记，并重复解释修改自动同步 | 只保留私人预览已开启、五分钟清理和关闭命令 |
| 界面缩放 | 长段解释后重复指向哪组滚轮调节 | 精简为文字倍率关系及两组可滚轮调节；选中值和文字预览保留 |
| FOV 适配 | 解释高 FOV 如何拉近菜单以及插件实现边界 | 精简为匹配客户端 FOV、仅调整菜单位置和默认 70° |
| 外链确认 | 「由于 Minecraft 的限制……」再描述第二次确认 | 精简为「确认后还需在客户端确认打开链接」；网址和确认动作保留 |

另清除八个无调用的旧提示资源：`click-set`、`click-switch`、`chat-delay-option-desc`、`teleport-allow-desc`，以及四个 `mention-*-desc`。这部分是资源清理，不宣称原来仍在界面显示。

共删除 16 个文案键，精简 7 个文案键，所有 16 种语言同步更新；不保留旧键回退。

## 明确保留

- 主菜单、语言、聊天、家和传送页的当前值、身份与坐标，及空状态下实际有用的恢复路径。
- 玩家对战规则、死亡自动开启和坐骑受伤等有实际行为影响的说明。
- 公告滚轮浏览、音乐不同鼠标动作、垃圾桶 F 键删除、载具驾驶与模型放置等非直观操作。
- 封禁姓名核对、地段删除与转让、世界重生成的建筑覆盖风险及备份提醒。
- 活动参与规则、资格、领取条件、地址和邮费要求，身份绑定及解绑方法。
- 音游时序与校准说明、基岩版字体限制、外链目标和客户端二次确认。
- 命令注册说明、主动调用的帮助、错误恢复建议、服务器状态与运维日志。

## 验证

界面结构回归测试检查入口动作、空状态、队列页码、唱片元数据与签名、网址确认和重要风险提示仍存在；治理布局测试覆盖移除说明后的空列表与正常列表。共享语言资源测试检查所有语言键与参数一致。构建验证不替代 Java／基岩客户端实机检查。
