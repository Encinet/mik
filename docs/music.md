# 音乐与音游

支持本地音频、NBS 红石音乐、LX 自定义音源搜索、公开歌单导入、实体唱片和唱片机队列。普通音频通过 Lavaplayer 解码、Plasmo Voice 播放；NBS 使用 Minecraft 音符盒声音。所需运行时库由插件加载。

## 数据目录

以下路径相对 `plugins/mik/`：

| 路径 | 用途 |
| --- | --- |
| `music/` | 管理员维护的本地音频与 NBS，递归扫描 |
| `lxmusic/local/` | 可信 LX 音源脚本，按相对路径排序；可用 `10-`、`20-` 前缀指定顺序 |
| `lxmusic/remote/` | 命令导入的受管理快照与 `sources.json` 订阅登记，不手工放脚本 |
| `cache/music/` | 在线完整音频及曲目元数据，跨重启复用 |
| `cache/lyrics/` | 独立歌词缓存，最多 256 MiB，按最近使用时间淘汰 |
| `state/music-disc.key` | 在线唱片签名密钥，须备份，不应编辑 |
| `state/music-playback.json` | 服务器播放统计 |

音乐没有单独的配置文件，`lxmusic` 根目录中的脚本不会加载。

## 命令

玩家命令：

- `/music`：打开本地曲目和已完整缓存在线曲目的音乐库。
- `/music search <关键词>`：同时搜索本地曲目和所有可用在线音源。
- `/music playlist import <平台> <歌单ID或链接>`：导入其他平台的公开歌单并打开临时歌单视图。
- `/music page <页码>`：切换当前音乐视图页码。
- `/music random`：从本地曲目和已完整缓存的在线曲目中获得一张随机唱片。
- `/music randomplay`：在 50 格内最近的已加载唱片机播放随机本地或缓存在线曲目。

管理员命令：

- `/music reload`：异步重载本地目录、URL 订阅和所有 LX runtime。
- `/music sources`：查看本地脚本、远程订阅、能力和健康状态。
- `/music sources import <url>`：导入 HTTP(S) 或绝对 `file://` 音源。
- `/music sources update`：立即检查全部远程订阅。
- `/music sources remove <remote-id>`：删除一个远程订阅和受管理快照。
- `/music cache`：查看在线缓存文件数、占用和配额。
- `/music cache clear`：清理在线缓存；正在播放的文件会在释放后删除。

命令中的文件 I/O、网络请求和脚本初始化不会阻塞 Bukkit 主线程。
`/music reload` 会分别发布本地音乐库、URL 订阅和 LX runtime 的结果：全部成功时
显示成功，至少一部分成功时显示保留旧状态的部分成功，三部分全部失败时显示失败及
各自原因。一个损坏的本地文件或失效订阅不会撤销其他部分已经成功发布的状态。

## 本地曲目与歌词

支持 `mp3`、`m4a`、`mp4`、`wav`、`flac`、`ogg`、`oga`、`aac`、`opus`、`mka`、`webm`、`nbs`。添加、删除或替换文件后执行 `/music reload`。

普通音频优先读取内嵌标签，其次读取播放后端和格式信息；歌曲名最终回退到相对文件名，歌手和专辑缺失时留空，不从文件名猜测。后端无法识别的文件不进入曲库。NBS 保留歌曲名、作者及原作者；格式和播放规则见 [NBS 参考](nbs-music.md)。

MP3、FLAC、Ogg、M4A/MP4、WAV 的内嵌歌词可直接使用：LRC 按时间戳同步，纯文本按已知时长均匀排布。歌词读取失败不影响播放。

在线歌词优先通过音源的 `lyric` action 获取，缺失时读取曲目信息中的安全 `lrcUrl` 和可用的 `trcUrl`。Action Bar 显示原文及翻译，缺翻译时使用罗马音；空时间戳行清空显示。歌词范围随唱片机设置更新。

## LX 音源与歌单

将可信 `.js` 脚本放入 `lxmusic/local/` 后执行 `/music reload`，或使用 URL 导入：

```text
/music sources import https://example.invalid/lx-source.js
/music sources import file:///srv/mik-sources/lx-source.js
```

`file://` 必须使用绝对路径。导入先在隔离环境初始化，再复制为受管理快照，始终执行快照。订阅在启动、reload、手动 update 及每 6 小时检查更新；HTTP 使用条件请求。内容变化且验证通过才替换，失败保留最后可用版本。删除订阅不会删除 `local/` 或 `file://` 原文件。

脚本须声明 `musicUrl`；MIK 查询健康音源声明的 `kw`、`kg`、`tx`、`wy`、`mg` 平台目录，再交给脚本解析播放 URL。可选的 `musicSearch` 优先提供搜索结果，无效或失败时回退平台目录。多个音源按稳定歌曲 ID 去重，保留部分成功结果。

搜索同时覆盖本地与在线曲目，保留各在线渠道内部顺序，跨渠道优先展示标题匹配更好的曲目；缓存状态不参与排序。相同查询合并并缓存 30 秒，最多 128 组，音源变化后失效。

| 玩家请求 | 连续额度 | 恢复速度 |
| --- | ---: | --- |
| 在线搜索、歌单导入 | 2 次 | 每 5 秒 1 次 |
| 主动播放在线曲目 | 3 次 | 每 10 秒 1 次 |

额度相互独立，离线清除；自动续播、区块恢复、本地音频和 NBS 不受限制。

公开歌单支持酷我、酷狗、QQ 音乐、网易云音乐和咪咕：

```text
/music playlist import wy https://music.163.com/#/playlist?id=123456
/music playlist import tx 123456
```

参数为数字 ID 或对应平台的标准链接，域名须匹配。按平台原顺序导入，最多 1000 首；超限提示加载数和平台总数。该平台须有健康音源提供 `musicUrl`。导入结果只保留在当前浏览会话，可逐首拿取唱片、播放或加入队列，不自动下载整个歌单。

音源连续失败 3 次后暂停 60 秒；单次初始化、搜索和 URL 解析最多等待 20 秒。`/music sources` 显示能力、健康状态、失败次数、恢复时间和最近错误。脚本可发起外部 HTTP 请求，只安装可信来源；接口和运行时能力见 [LX 扩展参考](lx-custom-source-extension.md)。

## 缓存与播放统计

在线歌曲边下载边解码，同一目标共享下载，完成后原子发布完整缓存；正在播放或加载的文件不会被淘汰。

| 限制 | 数值 |
| --- | --- |
| 单首音频 | 512 MiB |
| 总音频缓存 | 8 GiB |
| 同时下载 | 4 首 |
| 单次下载总时限 | 10 分钟 |
| 连接或响应体无新数据 | 15 秒后重试 |

连接错误、408、425、429 和 5xx 在 200 ms 后重试一次，仍失败则重新解析并最多尝试 4 个音源；失败提供者降级 60 秒。截断、超限和无效响应清理半文件。在线解码中断会重新解析下载一次，可定位时从故障位置继续；失败才报告错误。本地文件不会自动删除或重试。

达到配额后综合播放次数、最近使用和文件大小淘汰非活跃缓存；活跃文件导致空间不足时，新下载失败。成功识别的完整缓存会登记曲目元数据，可在重启后参与随机播放。

自然播完计一次播放。手动停止、换碟、区块卸载或停服时，已知时长须播放至少 70%，未知时长须至少 30 秒才计数。下载、搜索、拿取唱片、排队和加载失败不计数。统计后台原子写入，停服时刷新。

## 曲库与唱片机

曲库可在「全部音乐」和「NBS 专区」间切换，并按默认、播放榜或最近播放排序。左键拿取唱片，右键在附近唱片机播放；从唱片机选歌页进入时，左键加入该机队列，右键立即播放。详情显示歌名、歌手、专辑、格式、时长和可用的音频参数。

空手潜行右键唱片机打开控制场景。音乐模式提供曲库、队列、播放顺序、下一首及停止弹出；音游模式提供选曲、开始游戏和延迟校准。声音设置单独调整音量和范围。当前唱片及播放牌仅向各玩家显示虚拟模型，不生成真实实体。

队列支持播放、移除、前移、后移；清空队列不停止当前曲目。播放顺序有：

| 模式 | 自然结束后 |
| --- | --- |
| 列表循环 | 按顺序播放，末尾回到第一首 |
| 单曲循环 | 重复当前曲目；手动下一首仍前进 |
| 列表随机 | 随机选择，多于一首时避免连续重复 |
| 音乐库随机 | 从本地和完整缓存选择，排除当前曲目 |

自然续播要求范围内仍有玩家；手动下一首不受此限制。失败、手动停止和取消不会触发续播。队列与顺序为运行期状态，重启清空；音量、范围和用途模式保存于唱片机。

范围默认 64 格，最大 256 格；左右键粗调 32 格，滚轮细调 4 格，立即应用于音频、NBS 和歌词。普通音频只向已连接并启用 Plasmo Voice 的听众播放；发起者未连接时收到提示，其他听众仍可收听。NBS 不要求语音模组。

音乐模式按 `播放范围 × 0.5 × √(音量百分比 / 100)` 计算明显听闻半径。两台唱片机的听闻球相交或相切时，异曲拒绝启动，同曲共享播放进度。每台仍有独立空间声源，停止一台不停止其他；同步组只广播一次播放通知。音游不参与该协调。

MIK 与原版唱片均可通过漏斗、投掷器或正对唱片机的发射器装入；MIK 唱片验证并启动成功后才从来源扣除，临时唱片不可自动转移。「停止并弹出」也适用于原版唱片。在线实体唱片携带签名播放快照。

操作须在同世界、距唱片机 8 格内，离开菜单打开位置 3 格即关闭。拆除、区块卸载或离开范围后无法继续远程操作；区块卸载停止播放，重新加载或重启后按机内有效唱片恢复。

## 音游

选择玩法与难度后进入独立场景。位置锁定，视角可转；长按实际绑定的下蹲键约 600 ms 退出。传送、受伤、死亡、离线、停歌或换碟会安全结束。每位玩家独立保存判定、分数、连击和难度偏好。

| 玩法 | 操作与提示 |
| --- | --- |
| 下落式 | 热栏 1–4 格动作对应四轨，音符到判定线时按键；游玩中选中槽保持第 9 格，退出恢复原槽 |
| 环向来袭 | 转动准星对准水平 360° 飞来的方块，左键或右键命中；轨迹和亮度提示接近时机 |
| 星域点击 | 对准球形空间中的静止目标，四点接近笼收拢时点击；序号、星轨和离屏箭头指引顺序 |

鼠标玩法点击空处保持中性，不吞掉节拍；超时目标才计 Miss。游玩中相关挖掘、放置和实体交互被拦截，避免误改世界。星域点击需要至少两个俯仰带与两个深度层的可用空间；受遮挡且无法安全呈现的目标忽略，不计 Miss。轨迹链点击起点后跟随移动星体，在各发光检查点点击；无需长按，跟随提示本身不计分。

| 难度 | 最大音符密度 | Perfect | Great | Good | 得分倍率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 轻松 | 约 2.0/s | ±120 ms | ±200 ms | ±300 ms | ×0.80 |
| 标准 | 约 4.0/s | ±90 ms | ±150 ms | ±220 ms | ×1.00 |
| 困难 | 约 5.9/s | ±70 ms | ±120 ms | ±165 ms | ×1.15 |
| 专家 | 约 7.7/s | ±55 ms | ±90 ms | ±125 ms | ×1.35 |

音游先完成整首缓存和谱面分析，再倒计时开播。普通音频依据起音、重音、周期及局部变化生成拍点，不按曲风预设；NBS 使用音符、速度和循环的精确时间轴。分析最多并行两个任务，三种玩法及所有难度复用同一结果。

浏览玩法或难度不会开播；首位玩家真正进入后准备整曲，最后一人退出后停止声音与时钟并回到等待。完整谱面可供下一局从头复用。中途加入者有约 3 秒准备缓冲，不重置其他玩家。

自然结束显示分数、准确率、最大连击、各级判定和平均 Early/Late；主动退出或受伤、传送等中断不弹结算。Bedrock 的玩法和难度选择使用原生表单，实际游玩仍使用空间场景与实时输入。

### 延迟校准

音游控制页提供校准，无需放入唱片；首次游玩须先完成整套校准，并连接、启用 Plasmo Voice。

| 阶段 | 跟拍方式 |
| --- | --- |
| Minecraft 音频 | 听原版鼓点，使用热栏 1–4 格动作 |
| Plasmo Voice 音频 | 听连续语音流鼓点，使用相同按键 |
| 键盘视觉 | 静音，观察方块过线后按键 |
| 鼠标视觉 | 相同静音画面，改用左键或右键 |

四阶段均为 75 BPM、800 ms 一拍的恒定节拍。按提示先听或观察示范，出现跟打提示后操作。采样持续到结果稳定，漏拍或偶发错误只会延长当前阶段，不要求从头重来。

校准期间临时隔离其他 MIK 唱片机声音，其他听众不受影响；完成、取消或中断后恢复。结果保存于玩家数据，重连有效；右键校准入口可完整重置，重置或数据不完整时须重新测试。

Minecraft/NBS 和 Plasmo Voice/普通音频各有独立的判定与动画偏移，鼠标玩法另用鼠标与键盘差值。每次采样扣除当时网络往返延迟，正式游戏再动态补偿当前延迟；动画只应用音画偏移，不叠加网络往返补偿。

校准和开局时 RTT 超过 350 ms 会拒绝进入。运行中每秒检查，连续 3 次超过上限才结束；单次尖峰仅警告，恢复后清零。超限结束不保存未完成校准，也不生成自然结算。

## 资源限制

- 单个音源脚本 2 MiB，最多 128 个 URL 订阅。
- 音源 HTTP 请求、响应各 4 MiB，action 返回 2 MiB，每个脚本最多 16 个并发请求。
- 单次聚合搜索最多接受 200 首曲目。
- 单个 NBS 最多 16 MiB、4096 图层、20 万音符，速度范围 0.01–655.35 tick/s。
- 在线搜索、歌词和播放依赖管理员安装的音源及其网络可用性。
