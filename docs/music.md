# 音乐与音游

`/music` 打开曲库、歌单、最近播放、设备和音游。音乐只通过唱片机播放：普通音频使用 Plasmo Voice，NBS 使用 Minecraft 音符盒声音。

## 音乐工作台

左侧切换集合，中间浏览列表，底部控制一台唱片机或一个同步组。设备名称可打开快捷选择；切换目标不自动开始或停止播放。未选设备时提交歌曲，会先保留待提交内容，再选择目标执行。关闭菜单不停止声音。

设备详情等任务页放不下时，自动收起集合导航与完整播放栏，保留当前任务、输出选择和关闭入口。编辑名称、个人别名等字段时，表单独占阅读区；确认或取消后回到原页面。

- 歌曲名打开详情；每行和列表工具栏直接提供「插播并立即播放」「追加到队列」，另可加入歌单。歌曲按名称、歌手、时长、类型分列，未知歌手或时长显示「—」。
- 多选后操作只针对所选歌曲，按当前列表顺序提交；未选时隐藏批量动作。「选择本页」位于分页区，按实际显示的行选择，也可选择全部结果。翻页保留选择，改变搜索清空选择，切换集合退出多选。自己的歌单还可批量删除和移动。
- 「加入歌单」使用浮窗，可选择已有歌单或以这些歌曲新建歌单。内容在打开时固定，不随切歌改变，也不替换当前队列。
- 切换集合会关闭该集合的歌曲详情、歌单设置、导入和输入；队列、设备与音游面板保留。异步保存可以完成，但不会把界面拉回已离开的任务。

搜索通过聊天提交，回车后退出输入；表单字段使用原生输入，完成后返回草稿，确认才保存。操作与显示设置见[空间菜单](spatial-menus.md)。

## 歌单

「我的歌单」标题旁提供新建和导入。歌单支持名称、描述、公开/私有、复制、添加和删除歌曲；仅作者可编辑。公开歌单可播放、复制或收藏，分享命令为 `/music playlist <UUID>`。新建、导入或复制成功后直接显示曲目。

歌单目录、保存目的地和导入合并列表按实际阅读空间确定每页行数，表头持续显示，各页列宽一致。长名称通过提示读取全文；翻页保留当前任务和所选歌曲，改变搜索或切换集合后，旧页面的翻页回调失效。

歌单内同曲只保存一次，队列允许重复。曲库按名称、搜索结果按相关性、最近播放按时间、歌单按作者顺序排列，筛选保留来源的相对顺序。

曲目列表按实际阅读空间分页，按当前页的歌曲测量列宽；曲名按钮保持单行，宽高贴合文字，长曲名可在阅读范围内带动列表扩宽。横向放不下时，将歌手、时长和图标操作移到曲名下方，保留详情、插播、追加和加入歌单入口。曲名用尽可用宽度后仍过长时才省略，提示先显示完整名称，再补充时长、类型与歌手。多选或移动时只显示对应的选择或放置控件。

自己的歌单多选后点击「移动」，再选择目标歌曲之前或持续可用的「放到末尾」。移动对象及相对顺序在开始时固定，翻页和搜索只用于寻找目标，不重排隐藏歌曲；成功后按歌曲身份定位到移动结果，取消保留原顺序。列表发生冲突时拒绝旧操作，离开列表会结束放置。

每步编辑立即保存；最近 20 次编辑在 10 分钟内可尝试撤销，撤销仅针对当前歌单。歌曲详情可制作签名实体唱片。最近播放只记录本人提交且实际开始输出的歌曲，支持单条删除或清空。

## 搜索和一次性导入

`/music search <关键词>` 搜索本地曲库和可用在线来源。管理员在 `music/library/` 添加或替换本地音频与 NBS 后执行 `/music reload`。

导入支持酷我 `kw`、酷狗 `kg`、QQ 音乐 `tx`、网易云 `wy`、咪咕 `mg`：

```text
/music playlist import wy https://music.163.com/#/playlist?id=123456
/music playlist import tx 123456
```

也可在「我的歌单」中导入。链接自动识别平台，只有 ID 时先选平台；读取失败可修改后重试。预览中可改名、新建歌单或合并到自己的歌单。合并只追加缺少的歌曲，保留原有顺序。

导入期间收起集合导航，底部只保留输出选择，为表单和预览留出阅读空间；完成或关闭后恢复。预览只构建当前页的歌曲，数千首歌不会同时排入界面。保存时操作区显示真实状态，完成后恢复可用操作；「重新获取歌单」使用刷新图标。

导入只读取元数据，不下载整单音频，部分结果会标记；导入后不持续同步外部来源。将私有歌单的歌曲提交给公共唱片机，只公开所选曲目，不公开原歌单名称、链接或未提交歌曲。

## 设备与远程操作

空手潜行右键唱片机，进入该设备或所属同步组的队列，并将底部播放栏指向它；符合现场条件时自动记录。「播放设备」入口始终打开设备列表，可按全部、已记录、附近未记录及同步组筛选。列表明确标出当前设备、状态、位置与曲目：「使用此设备」切换底部播放栏和后续歌曲的提交目标；「管理」打开该对象的设置，不切换播放目标。详情中的「返回设备列表」保留筛选和页码。

详情中可「记录以远程控制」。附近未记录对象离开范围后收起，已记录对象仍保留，未加载时显示离线。离线或无权限的对象仍可查看管理信息，使用按钮说明不可用原因。

现场范围为 8 格。远程操作要求个人记录与设备身份匹配、至少一个输出已加载，并保有所有成员位置的「控制音乐设备」地段权限；每次操作重新检查。播放和列表查询不加载区块。取消记录不停止播放；个人别名、同步组记录与成员各自的记录独立。

位置显示相对方位、距离，必要时补充高度差或世界名；提示中保留精确坐标。控制界面会标记 32 格内已加载且仍有权限的最近四台设备，优先正在调整的成员。同步组成员使用固定短编号与颜色；单行加粗名牌由客户端平滑朝向视角，长名称省略后仍可在菜单内查看。唱片机显示同色、可穿墙的发光描边，不持续发送粒子。名牌和描边与菜单重叠时隐藏，移开后恢复；暂停或关闭菜单后清理标记。

「传送到旁边」针对一台明确的唱片机，同步组在成员旁提供入口。需已记录或身处附近，并有控制权限；点击后可异步加载目的地区块，再校验身份、权限和周围两格内的安全落点。成功后朝向唱片机并关闭菜单；失败保留菜单并说明原因。等待期间关闭菜单、退出或停用功能会取消请求。

设备详情提供队列、设置，同步组另有成员页。独立设备设置音量和范围，同步组设置总音量，成员保留自己的音量与范围。管理页标题与底部「播放到」分别说明正在管理和正在控制的对象；切换播放目标不替换管理页或其草稿。队列编辑属于所查看的设备，底部播放键控制「播放到」所指设备。快捷选择不会覆盖歌单任务或同步组草稿。

任务标题保持居中，管理操作独立成行，宽度按实际内容计算。设备详情在高度不足时分页展示管理操作、位置、分类和设置，标题与关闭入口持续显示。

设备与同步组目录、播放目标浮窗按实际阅读空间分页，建组成员选择共用同一目录。空间足够时保留完整方位列；窄处或集合较大时显示紧凑卡片，仍显示状态、位置和曲目，坐标和完整内容可通过提示查看。建组时仅保留勾选、名称、状态与位置，歌曲内容通过队列来源查看。位置文字只读；无权限的设备不能加入，已选成员仍可移出。关闭目标浮窗后，旧回调不再选择目标或请求重绘。

### 同步组

多台设备通过同步组共用队列、进度、播放模式和时钟，目录只显示组，成员在组内管理。

1. 从「播放设备」点「创建同步组」，或在单台唱片机详情点「与其他设备合为组」。后者自动勾选正在查看的唱片机。建组页面直接显示成员勾选列表，选 2–16 台可控制的独立设备；名称已预填，可自行修改。
2. 列表中没有目标时，点「在游戏中选一台」，菜单暂时关闭；空手潜行右键目标唱片机，将它记录并加入当前草稿后自动返回。已有选择会保留，重复点击已选设备不会取消勾选。此时的世界点击只用于选择成员，不切换播放目标。重新用 `/music` 打开菜单会结束这次场景选取，继续编辑草稿。
3. 默认采用首个选中设备的数字播放内容，可改用其他成员的队列、当前曲和进度；实体唱片不算数字队列。全部为空时省略来源选择。未提交的勾选不改变播放，「取消」返回来源页面。
4. 点击「创建同步组」保留所选内容并停止原播放；来源有可播放内容时还可「创建并播放」。完成后打开新组的成员页，底部播放栏指向新组。来源变化或设备已入组时拒绝旧提交。创建后自动记录组，并保留各设备入组前的内容与检查点供恢复；支持定位的媒体可恢复所选进度。

选择成员期间，页面收起曲库导航，底部栏只保留当前输出选择，为设备列表留出空间；创建或取消后恢复导航与完整播放控制。队列来源通过来源按钮选择，和底部当前播放目标分别显示。

同步组详情持续提供「添加设备」，复用同一勾选和场景选取流程，提交后新设备直接跟随共享播放；管理其他同步组时添加成员不切换底部播放目标。移出或解散时选择「恢复入组前内容」或「保留同步组内容」；移出设备保留所选内容并停止，其余成员继续。剩一台仍保留组身份，移出最后一台则删除组及其个人记录。

每次歌曲提交固定一个播放目标并重新鉴权，只写入一次队列。提交成功但输出失败时，重试仅恢复输出，不重复插入歌曲；追加操作的重试不会自动开播。队列变化或后续停止会使旧请求失效。同步组可单独重试失败成员，正常成员和共享队列保持不变。

## 播放与队列

| 动作 | 效果 |
| --- | --- |
| 插播并立即播放 | 立即切歌，保留原队列；批量内容按顺序播放一次，再继续原队列 |
| 追加到队列 | 加入基础列表末尾并参与循环；保持当前曲、进度与状态，暂停或停止时不会开播 |
| 清空待播 | 当前歌曲结束后停止 |
| 停止 | 停止输出，保留内容 |
| 暂停/继续 | 保留进度；仅支持相应能力的媒体可用 |

播放栏显示当前曲和进度；已知时长且支持定位时，可点击进度条、滚轮前后调整五秒，或右键输入 `m:ss`、`h:mm:ss`、秒数。未知时长不提供可点击时间轴；不支持定位时只读。切歌、换目标或权限变化后旧操作失效。

队列分为一次性待播与歌单续播。移动只限同一分区的待播条目，当前曲和历史不能作为目标；随机候选只可移除，按序插播仍可移动。编辑不改来源歌单，撤销绑定当前设备，播放程序变化时拒绝旧放置。「将队列存为歌单」固定打开时的当前曲和实际待播，按顺序去重，不包含历史。

队列按实际阅读空间分页，每行标明一次性待播、歌单续播或随机候选，重复歌曲仍分别对应各次播放出现。窄处切换为紧凑行，名称提示优先显示分区、时长与歌手，选择和移动仍使用原控件。移动期间保留「放到末尾」入口，提示说明所属分区；成功后定位到移动条目，字号或菜单倍率变化不会把定位换成其他歌曲。切换正在查看的设备或详情分类会清除旧定位，旧页面的选择和翻页操作须核对设备、检查器与播放程序版本。

播放模式为顺序、列表循环、单曲循环、轮内不重复的随机。单曲循环先处理明确插播的一次性歌曲，手动下一首可离开当前曲。上一首在当前曲已播放超过 3 秒时从头播放，否则返回实际历史。

音量为 0–100，范围为 8–256 格、默认 64 格，均可用滑条或旁边数值框设置。滚轮每次调整 5% 音量或 4 格范围，数值框支持任意范围内整数。同步组总音量保留成员的相对音量；保存失败会恢复已存读数并说明原因。

不同播放会话的听闻范围明显冲突时阻止启动，可停止冲突设备、减小范围或建同步组。同一听众只接收组内一个输出；成员离线不重置其他成员，重新加载后可跟上播放。重启保留程序和检查点，等待手动继续。

手动启动或切换数字歌曲会清空槽内实体唱片，**不返还原唱片**。插入实体唱片会暂停数字输出，自动续播不覆盖后来插入的唱片，实体播放失败保留物品。停止、清空待播和弹出唱片是独立操作，实体唱片及自动化转移仍受地段保护。

## 音游与校准

「音游房间」列出附近唱片机，可创建或加入；同步组成员按单台设备列出。创建需现场与地段控制权限，加入已有房间不要求设备控制权限。房间绑定一台唱片机，参与者须在现场；该输出在音游期间暂时退出组音乐，其他成员继续。

房主在曲库多选一首作为曲目，每位玩家选择玩法、难度并准备；修改选择不直接开播。玩法有下落式、环向来袭、星域点击。音频和谱面就绪后，房主让已准备玩家开始；中途加入使用个人倒计时。长按实际潜行键约 600 毫秒退出，受伤、传送、死亡或离线也会退出，结果页可返回房间。

独立玩法与难度设置页按实际阅读空间分页，难度名称的提示保留密度、判定窗口和倍率说明。「开始」与返回入口持续显示，翻页和选择不自动开局；旧页面的翻页回调不会改变新打开或已挂起的选择页。

个人准备区提供延迟校准，包含 Minecraft 音频、Plasmo Voice 音频、键盘视觉、鼠标视觉四阶段；完成前保留旧结果，取消不保存半套数据。校准与开局检查网络延迟，算法和限制见 [NBS 参考](nbs-music.md)。

## 管理与数据

| 命令 | 用途 |
| --- | --- |
| `/music reload` | 重载曲库和 LX 来源，保留个人数据 |
| `/music sources` | 查看来源状态 |
| `/music sources import <URL>` | 导入可信音源脚本 |
| `/music sources update` | 检查受管理音源订阅 |

数据位于 `plugins/mik/music/`；`settings.yml` 修改后需重启，`/music reload` 只刷新曲库和来源。配置、目录、备份与清理见[音乐文件与配置](music-storage.md)，脚本协议见 [LX 音源接口](lx-custom-source-extension.md)，代码职责见[音乐架构](music-architecture.md)。

内部异常查服务器日志：`Music workspace failed` 包含玩家 UUID、页面和完整堆栈，`Music playback failed` 包含播放目标。
