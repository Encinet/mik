# 载具

从主菜单的「载具工作台」进入，或用 `/vehicle` 打开同一工作台。命令只保留这个入口，全部操作通过控件、选项和字段表单完成。

## 工作台

| 区域 | 操作 |
| --- | --- |
| 附近载具 | 选择同世界 32 格内的可访问载具；按距离排列 |
| 所有可访问载具 | 查看拥有、公开或有管理权的实例；每项显示模型、短编号和位置 |
| 单车页 | 驾驶、乘坐、离开、仪表盘、发动机、HUD、燃料、维修、访问权限、确认移除 |
| 模型库 | 新建、采集、导入、编辑、复制、生成、删除及继续草稿 |
| 模型采集选区 | 原点、半径选取、逐项选择、瞄准整组选取、清空、从选区建模 |

`mik.vehicle.use` 允许驾驶和使用可访问载具。所有者或 `mik.vehicle.admin` 可以维护、变更访问权限和移除自己的目标；管理员另可制作模型、生成和重载。无权限入口不显示；距离、驾驶位和维护条件在提交时再次检查。

单车操作绑定所选实例，不会重新寻找最近载具。载具被移除或重载、驾驶座改变、会话过期时，旧回调失效。移除、删除模型和重载均先确认；失败保留原状态，不扣维修材料。

## 缩小浮空的 3D 编辑器

选择模型的「编辑」后，模型默认缩小并浮在面前。预览按几何范围适配，最大轴通常不超过 2.8 格，默认比例至多 60%；可放大、缩小，也可重新摆放到面前。比例只影响编辑展示，保存后的模型、碰撞体、座位和物理参数保持实际尺寸。

模型本身就是操作区域：

1. 右击部件，或先从左侧选择部件、座位、碰撞盒、支撑点，再点选对应标记。
2. 选中后在模型上方切换位置、旋转、缩放、座位出口或碰撞盒尺寸。详情和展示属性打开字段与选项面板。
3. 右击红 X、绿 Y、蓝 Z 的正负控件调整。位置步长按实际模型单位计算，缩放预览不会改变调整量。滚轮切换步长。
4. 点车头箭头，再选模型哪一侧作为正面。换向会同步部件、座位、出口、碰撞盒、支撑点、重心及惯量，保持预览几何位置。
5. 右侧可直接保存、撤销、重做、放大、缩小和重新摆放。潜行右击或「现场编辑工具」返回详细设置。

个人预览仅自己可见，不修改源实体。停止修改五分钟、离开预览 32 格、跨世界、传送、区块卸载或退出时清理实体和现场输入；草稿在当前在线会话中保留，退出或功能关闭时释放。

### 精确设置

详细设置保留组件分类和参数分组，按当前载具类型显示适用字段：

- 部件：方块、主手物品、多行文字、选区内容及主手 Axiom 组合；独立的位置、旋转、缩放、动画与展示属性。
- 座位：驾驶位、乘客位及各自出口；复制驾驶位会生成乘客位，保持单一驾驶位约束。
- 碰撞盒：中心、完整宽高长、自动包围及两点建盒。先标第一角，再标空间对角；无厚度或越界会拒绝提交，保留第一角供重试。
- 支撑点：车轮或起落架接地点、船的浮力采样点。
- 参数：车身、发动机、燃料及船/飞机专用参数；速度界面显示 km/h，保存时换算为方块/秒。

绝对坐标和相对移动表单使用独立 X/Y/Z 字段，不要求输入命令片段。取脚下位置使用模型采集时的世界原点；瞄准缩小预览表面时逆向换算到真实局部坐标。瞄准世界表面仍使用采集原点。网格吸附按实际局部坐标和所选步长计算。

视线放置先收起设置面板，待开启点击结束后，再用主手右击确认；潜行右击取消。工具 30 秒后过期，草稿变更、撤销、保存或传送也会取消。预览表面点选受方块遮挡限制；显式操作控件可在模型内部使用。

编辑有原子校验、撤销和重做。字段先验证候选草稿，确认才应用；旧版本表单不能改到后来切换的草稿。保存并继续保留编辑现场；保存并结束返回模型库；放弃未保存修改需要确认。

## 采集、导入与生成

世界实体采集流程：

1. 在采集选区页把脚下设为原点，水平面向希望使用的正面；局部 +Z 向前，+Y 向上。
2. 选择半径，或浏览附近展示实体逐个切换选择。也可瞄准展示实体后右击选中整组；从成员追溯根实体，遍历连接树并替换原选区。
3. 选择「从选区创建模型」，点击汽车、船或飞机，再填写模型 ID。
4. 在浮空 3D 工作台调整和保存。采集只复制数据，不拆散或删除原展示实体。

主手 Axiom 组合从「导入」进入，选择类型并填写 ID。它会复制部件和展示属性，按几何范围生成默认座位、碰撞盒和支撑点；源物品与草稿彼此独立。编辑现有草稿时也可追加主手组合或当前世界选区。

模型 ID 使用小写字母、数字、`_` 和 `-`，至多 48 个字符。新建、复制和导入不会覆盖重名模型，也不会丢弃正在编辑的另一份草稿。

在模型详情选择「生成载具」后，用独立 X/Y/Z 字段确认世界坐标。默认位置为前方四格、上方一格，水平朝向使用生成时视角。生成检查地形、世界边界、已加载区块、其他载具、配额和保护事件。

## 驾驶与维护

右击载具可进入驾驶位，潜行右击进入乘客位；也可在单车页明确选择座位。驾驶使用原版输入：W/S 与 A/D 控制行驶，滚轮换挡或调节推进，换手切换辅助模式，潜行退出。飞机通过抬头/低头控制俯仰。驾驶席有燃料且未完全损坏时自动启动，离开驾驶席会熄火。

仪表盘按驾驶、变速箱和详情分层。驾驶面板保留原版移动输入；变速箱提供 P/R/N/D、自动/手动、直接选前进档与逐档升降；船和飞机显示推进及辅助控制。详情提供速度、转速、燃料、消耗、预计续航、车况、乘员、位置与航向。可回工作台；关闭面板保留 BossBar，HUD 开关控制仪表显示。

自动/手动切换不会重置选档杆、实际档位或正在换挡的状态。手动换挡含离合延迟，行驶超过 0.5 方块/秒不能挂 P 或切换前后方向；预计降挡超转速时拒绝。W/S 同按不给油，手刹优先，腾空汽车没有地面牵引力。

加油和维修需在所选载具 32 格内、停车并熄火。主手煤或木炭补充最多 10 燃料，铁锭补充最多 10 车况；只在保存成功后消耗一个材料。移除要求停车且无人乘坐，只删除实例。实例默认私有，公开按钮允许他人驾驶和乘坐，所有权保持不变。

内部单位为方块、秒及游戏尺度质量，一方块按一米展示。燃料使用游戏单位，消耗及续航按实际状态估算，不预测路线；无法估算显示 `—`。不编造水温、胎压等未模拟读数。

## 配置与模型编辑

`plugins/mik/vehicles.yml` 管理总预算：

```yaml
maximum-active: 16
maximum-instances: 256
maximum-per-owner: 16
activation-distance: 80
disabled-worlds: []
```

设置在启动时读取。实例上限最多 512，激活上限最多 64；模型最多 256。大量模型零件会增加实体同步和客户端渲染开销，应先测量再增加预算。

蓝图保存在 `plugins/mik/vehicles/definitions/<id>.yml`。可通过游戏内参数/组件表单 修改以下字段；也支持停机后维护文件并执行重载：

| 字段 | 用途 |
| --- | --- |
| `mass`, `center-of-mass`, `inertia` | 质量、相对模型原点的重心、局部三个轴的惯量 |
| `colliders.<编号>.center/half-size` | 复合盒碰撞体；尺寸是半尺寸，不是全尺寸 |
| `seats.<编号>.position/exit/driver` | 座位位置、退出点、是否驾驶位；必须恰好一个驾驶位 |
| `supports.<编号>` | 车轮/起落架接地点，船的浮力采样点 |
| `support-length`, `grip` | 悬挂支撑长度、地面抓地系数 |
| `engine.*` | 扭矩、怠速、限转、惯量、轮径、主减速比、倒档及前进档比、换档时间 |
| `buoyancy` | 船体采样点的浸水浮力系数 |
| `wing-area`, `lift` | 固定翼面积与升力系数限值 |
| `fuel.capacity/consumption` | 容量与工作消耗率；怠速也消耗燃料 |
| `maximum-speed` | 游戏尺度安全速度上限 |
| `parts.<编号>.matrix` | 列主序的 4×4 仿射局部矩阵，保留缩放和旋转 |
| `parts.<编号>.animation` | `BODY`, `FRONT_WHEEL`, `WHEEL`, `PROPELLER`, `RUDDER` |

零件动画绕零件自身的局部原点旋转；轮胎、舵和螺旋桨需要在模型制作时设置合适的旋转中心。预设只提供车身，不自动猜测机械零件。

飞机可用机身、左右机翼等多个盒体；船的浮力点与实体碰撞体分别配置。定义支持最多 16 个碰撞盒、16 个座位和 16 个支撑点。所有尺寸、矩阵及物理参数经过有限数值和大小限制校验。

停稳全部载具，关闭全部发动机，让所有乘客下车后在工作台选择「从文件重载模型」。重载先读取并校验全部蓝图和现有实例，再整体替换。失败保留原运行配置。不能删除仍有实例引用的定义，也不能使实例当前燃料/档位超过新定义限制。

## 碰撞、区块和保存

使用旋转盒的分离轴扫掠检测，世界障碍来自方块的真实碰撞形状；复合盒可检测机翼而不仅是载具原点。速度与角速度影响内部子步数，最终位姿每服务器 tick 同步一次。载具之间按复合盒阻挡；当前不处理乘客之外的生物撞击伤害。

座位使用隐藏的标记盔甲架，`VehicleSeatMover` 将 Paper 26.3 的原生位置同步隔离在一个适配器内。持续移动不调用 Bukkit 玩家传送，不改变玩家自由观察的朝向，也不会把载具运动记为玩家主动传送。升级服务器基线时应重新验证此适配器。

不会主动加载区块。未加载区块、世界边界和高度边界作为障碍处理。附近玩家触发实例激活，远离玩家且已静止、关闭发动机的地面载具休眠。空中实例在区块仍加载时继续计算；区块卸载时保存逻辑状态并撤掉实体，再加载时保留动量恢复，发动机不自动重启。无观察者载具受同一激活预算约束，不无限加载世界。

实例统一保存在 `plugins/mik/vehicles/instances.yml`，每 30 秒检查点保存，生成、维护、权限更改和删除立即保存。文件通过同目录临时文件和原子替换写入；不支持原子移动的文件系统使用替换移动。YAML 损坏、未知版本或缺失定义会阻止模块启动，不用空集合覆盖现有数据。

展示、点击和座位实体不持久化。重新启动及区块载入时清理遗留的带标记实体，再按实例状态生成，避免重复载具。

## 保护插件接入

`VehicleUseEvent` 是可取消事件，提供玩家、操作、实例 UUID（捕获时为空）和位置，包含捕获、生成、进入、维护及移除。

`VehicleMoveEvent` 提供实例 UUID、所有者 UUID、可空的驾驶员和本 tick 的起止位置。取消后恢复原位姿并阻止本次移动。两个事件是区域保护接入点，不代表模块自动接入了全部地段或第三方保护规则；生产服应按自己的策略注册监听器。

## 功能限制

当前范围是游戏尺度车辆，不是完整机械仿真。没有直升机、帆船、自由行走甲板、完整手动离合、飞机相机滚转、降落伞、资源包图形仪表或真实发动机声采样。基础 HUD 无资源包即可使用；真实座位按模型的三维位置移动，玩家外观和相机仍遵守原版骑乘表现。
