# 选区重生成与世界升级

模块读取 FastAsyncWorldEdit 选区，在临时影子世界中使用当前服务器生成器异步生成源区块，
后台比较差异，再在主线程按每 tick 预算分批写入。

## 命令

```text
/regen                         # 显示命令用法，不修改世界
/regen preview                 # 预检全部方块重生成；等同 preview blocks
/regen preview blocks          # 预检全部方块重生成
/regen preview blocks <类型...> # 只预检当前属于指定类型的方块
/regen preview upgrade         # 预检地形、结构、方块实体、生物群系与结构元数据升级
/regen preview biomes          # 只预检生物群系升级
/regen show                    # 显示待应用计划或当前 FastAsyncWorldEdit 选区
/regen apply                   # 应用最近一次仍有效的预检计划
/regen status
/regen cancel
```

先选区并执行 `preview`，预检完成后通过确认框或 `/regen apply` 应用。计划有效期两分钟，
固定预检时的世界、选区、操作模式和过滤条件。

## 选区预览

预检开始时会自动向发起者显示玩家专属粒子，其他玩家看不到，也不会创建展示实体或
加载额外区块。青色表示已保存选区的边界；预检完成后，橙色表示将变更方块的空间抽样，
红色表示可能被覆盖的容器、告示牌、刷怪笼等方块实体抽样。粒子与确认操作使用同一份
克隆选区，在确认、取消或两分钟超时后自动停止。

`/regen show` 会重新显示正在等待应用的计划；没有计划时，则将当前 FastAsyncWorldEdit 选区
显示 30 秒。大选区轮播玩家附近的采样点。预览展示边界和高风险方块实体，
普通玩家建筑需现场核对；执行前保留世界备份。

## 预检内容

预检会统计：

- 与当前版本生成结果不同的方块数量。
- 需要修改的 4×4×4 生物群系单元数量。
- 当前版本生成器在选区涉及的结构数量，以及可完整迁移原版结构元数据的结构数量。
- 会被生成结果覆盖的现有方块实体数量，例如容器、告示牌和刷怪笼。
- 因接触选区边界而必须跳过的生物群系单元数量。
- 从未生成、因此不会由工具创建或修改的目标区块数量。

## 写入范围

- 每一个方块写入前都来自已经克隆的选区计划，比较阶段也逐方块调用选区包含判断。
- 目标世界只异步加载已经存在的区块，加载参数禁止生成。未生成区块直接跳过，避免
  为一个局部选区生成整个区块并间接改变选区外地形。
- 生物群系在 Minecraft 中按 4×4×4 单元存储。只有单元内所有有效世界方块都位于
  选区时才会写入；部分落在选区外的单元整体跳过，避免一次写入越过边界。
- 结构方块与方块实体随地形复制。包围盒完整位于长方体选区内，且目标区块都已生成的
  结构，同时复制 `StructureStart` 与交叉区块引用，供 `/locate` 和特殊生物生成识别。
  其他结构只更新选区内的物理方块。
- 确认操作只允许迁移预检明确列出的结构身份；应用阶段不会因为重新生成结果而自行
  扩大结构元数据范围。结构起点写入后会立即刷新服务器的原版结构检查缓存，不必重启
  才能让 `/locate` 看见结果。

## 调度与取消

目标世界和影子世界均使用 Paper 异步区块加载。结构统计直接读取已经生成完成区块中的
结构起点与引用，不会通过 Bukkit 结构查询同步加载其他区块。后台最多同时比较两个区块，
每个任务最多缓存六个区块计划；主线程写入总预算为每 tick 3 ms、最多 4096 项，并在
多个玩家任务间轮转。结构起点与区块引用也计入同一套每 tick 写入预算，不会一次性在
主线程批量写入。

`/regen cancel` 会停止后续规划和写入，已经应用的变更不会自动回滚。预检期间取消不会
修改世界；等待应用期间取消会使一次性计划失效。
