# 空间菜单

从 `/menu` 打开主菜单和个人设置。菜单使用玩家专属虚拟展示，不写入方块或区块；按钮提交的操作仍由服务端校验权限与当前状态。当前没有基岩版专用菜单或 DDUI，Geyser 的呈现与输入取决于协议转换能力。

主菜单中央入口按图标和标签的实际尺寸尽量排成接近方形，同样合适时优先竖向排列。同组入口等宽等高、边界对齐，图标和文字保持原有比例与字号。字号、界面大小或 FOV 使阅读空间不足时，入口会分页，顺序与操作保持一致。

## 操作

- 对准按钮点击；禁用项显示原因，返回恢复上一级。
- 姓名、资料、时间和读数等只读内容保持静态；省略文字可指向查看全文，不产生操作高亮、位移或悬浮音。禁用控件也安静显示原因；有可用动作的控件才提供操作反馈。
- 多页列表可用前后页按钮或滚轮。指向哪个列表就翻哪个，首末页停止；指向音量、进度等数值控件时优先调整数值。
- 普通表单先从字段目录选择要查看的字段，再点击预览，在 Dialog 编辑完整草稿；完成返回预览，最终确认才保存。浏览字段保留其他草稿，Dialog 中的取消或 Escape 保留进入编辑前的值。
- 搜索使用聊天输入：点击后发送一条查询，回车即退出接收。编辑时叉号取消，提交后叉号清除；无效输入保留旧查询，需再次点击重试。后续消息恢复普通聊天。
- [名牌](name-tags.md)使用持续聊天预览，直到确定、取消或离开。搜索、表单和预览均不设超时，关闭所属页面后释放输入。
- 补充说明显示在准星旁，可移入阅读，左击关闭；覆盖区域不执行后方操作。需要按钮或长篇阅读的内容另开详情浮窗。

主菜单左侧是资料、身份与[最近公告](announcements.md)，中间是功能入口，右侧是站外链接、治理动态及当前地段公告。AFK、PVP 快捷项显示当前状态并直接切换；PVP 详细选项位于设置页。家列表可按名称搜索，先选择地点，再点击传送；按实际阅读空间分页，翻页保留已选目标，改变查询重新筛选。

详情卡片、标题和状态优先完整展开，只有整页放不下时才显示摘要，并保留悬浮全文；可用空间恢复后自动展开。家的详情优先显示完整名称、世界、坐标和距离。

管理员可用 `/pvp admin` 浏览在线玩家，左击卡片切换其 PVP 偏好，右击或点击设置按钮进入详细选项。目录按阅读空间分页，字号或名单变化时保留阅读对象，返回继续原位置；卡片提示保留完整状态和战斗信息。操作时重新检查权限与在线对象，强制规则仍决定实际 PVP 状态。

功能操作见[音乐](music.md)、[治理](governance.md)、[公告](announcements.md)、[地段](plot-board.md)和[载具](vehicles.md)。

## 菜单主题、大小与文字

设置页左侧切换分类，右侧直接操作当前设置；切换不增加返回层级。语言使用接近方形的紧凑网格，优先一页展示；界面与文字的大小、字号、主题和动态选项同页显示，无需切换分组。较长的设置项按单列向下阅读，高度不足时翻页。聊天分组目录优先放在当前选项上方，空间不足时整体换向。百分比和角度保持紧凑排列，面板随实际内容收放。名称标签使用同一[名牌编辑器](name-tags.md)，前缀和后缀同时展示，离开分类会放弃未确认草稿并结束聊天接收。

| 设置 | 可用值 |
| --- | --- |
| 菜单主题 | 炭灰（默认）、暖棕、森林、自定义 |
| 菜单大小 | 70%、80%、90%、100%、110%、120%、130% |
| 文字大小 | 70%、80%、90%、100%、110%、125%、140%、160%、180% |
| 减弱动态 | 减少位移、晃动和装饰旋转，保留状态反馈 |

界面偏好的大小、文字、主题与动态选项在同一表单中展示，短选项按可用宽度换行；预览、FOV 和恢复大小入口持续显示。大小和文字默认均为 100%，独立叠加；指向对应控件滚轮调整，端点停止。恢复两项为 100% 时保留主题、FOV 和动态偏好。

选择自定义会复制当前预设的全部颜色与透明度，之后独立保存；已处于自定义时再次选择保留修改。切换其他预设后再选择自定义，会重新复制当前预设。通过「编辑配色」分页选择颜色角色，在 Dialog 修改 `#RRGGBB` 和 0–100% 不透明度，确认后即时应用。自定义颜色不受预设对比度校验限制。

主题影响面板、控件状态、输入框和浮层；名牌等业务显式配色及图片原有像素保持原意。切换主题保留当前位置、尺寸和草稿。图片需要支持 Axiom 图片注解且开启注解显示的客户端；其他客户端显示替代文字，下载失败时 Axiom 显示检查格。

偏好保存在 `plugins/mik/menu-settings.yml` 的玩家记录下：

| 字段 | 内容 |
| --- | --- |
| `scale`、`text-scale` | 菜单与文字倍率 |
| `theme` | 主题 ID，自定义为 `custom` |
| `custom-theme.<role-id>.color`、`.opacity` | 自定义主题的完整颜色与透明度，无基础主题继承 |
| `reduced-motion` | 减弱动态 |
| `field-of-view` | 手动 FOV |

未知主题或损坏的自定义记录整份回退炭灰并记录警告。

## FOV 适配

FOV 须手动匹配客户端常规视野，范围 30°–110°，默认 70°。预设间隔 10°，按钮或滚轮每次调整 5°，精确输入接受范围内整数。无效存档回退默认值。

服务端据此安排菜单，不读取或修改摄像机。冲刺、飞行、效果、望远镜、模组变焦和窗口比例不会自动同步。默认 70° 的普通前方面板名义距离为 2.8 格；窄 FOV 会增加观看距离，保持界面体量，较高 FOV 不再放大菜单。菜单与文字倍率独立，世界锚定标记不使用此适配。

## 布局与避障

普通前方页面在宽 6 格、高 3 格的绘制范围内布局，正文、侧栏和工具共同分配空间；场景外标题、模型和碰撞留白另计入避障。主菜单两侧组件独立分页，设置分类目录在空间不足时也可翻页。音乐任务接替曲库的主区域，关闭后恢复浏览；地段矩形目录按实际高度分页，字号变化后保留来源位置。背景随当前内容增大或收缩，同页更新保持观看基准。首屏加载占位不锁定正式比例；已有内容刷新时继续展示，完成后更新。前方面板超过阅读范围时可能原位等比缩小。

主区保持平整，左右侧栏水平内收，上下工具面垂直倾斜；文字、图标、背景和点击区域整体对齐。长译文与大字号可换行、减少列数或分页，普通正文和按钮不持续漂浮。

菜单检查已加载区块中的碰撞形状和附近可见实体模型，包括玩家、生物、载具、悬挂物、原版坐垫、末影水晶、掉落物、下落方块、已点燃的 TNT、投射物，以及方块／物品／文字展示。地面或顶棚挤压整页时调整位置，必要时将菜单及其视点距离同比缩小，保持视野中的大小、排版与点击位置；详情浮层和恢复过程遵循同一规则，不设置固定物理距离下限。不强制加载区块或移动原实体。打开前检查完整阅读范围，之后复核移动障碍；只有视点进入不透明体内部等无法验证显示空间时才暂停呈现，保留菜单与草稿并自动恢复，不提示空间不足或关闭菜单。

实体是否具有物理碰撞不影响模型采样。盔甲架及其装备按姿态、大小与缩放估算，包括没有碰撞盒的标记盔甲架；隐形生物的可见装备仍参与避让。不可见控制实体和纯粒子特效不占据避让空间。自定义字体、资源包物品模型和非盔甲架生物的装备使用估计边界。

贴墙或固定在平台边缘的世界面板保持实际位置和物理大小，FOV 与菜单大小设置不移动或缩放它们；文字大小变化在原范围内重新排版或分页。多个面板共存时，对准最近的可见正面操作。打开普通菜单会暂时隐藏这些面板，关闭后恢复。

开发接口见[空间菜单 API](spatial-menu-api.md)，实现边界见[菜单架构](spatial-menu-design.md)。
