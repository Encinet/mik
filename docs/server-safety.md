# 世界安全保护

MIK 启用时自动注册以下全局保护，不需要额外配置或权限。

## 液体

- 阻止水、岩浆流动时冲毁方块，包括从含水方块、水下植物流出的水。
- 玩家主手、副手倒桶，以及发射器倒桶，使用相同的目标保护规则；鱼、蝾螈和蝌蚪桶中的水也受保护。
- 保留空处放水、液体正常流动与混合、灭火、方块含水和水下植物行为。投掷器仍可正常抛出桶物品。
- 阻止岩浆引燃周围方块。

## 爆炸与危险实体

以下能力由原 NoAnyBoom 插件迁入 MIK：

- 阻止爆炸破坏方块，保留爆炸效果、击退和风弹触发按钮、拉杆、钟等交互。
- 将实体受到的爆炸伤害设为零，覆盖普通爆炸、床与重生锚、烟花、风弹，以及服务器爆炸伤害标签中的数据包伤害类型。
- 阻止爆炸起火，以及爆炸破坏画和物品展示框。
- 保护盔甲架、末影水晶、船和矿车，覆盖这些实体独立的破坏与受伤路径。
- 恢复爆炸时已被移除的床和重生锚；床会恢复两部分并清除占用状态，已有方块不会被覆盖。
- 禁止凋灵、末影龙生成；不移除世界中已有的实体。

这些保护由 MIK 的生命周期管理，停用时注销监听器。部署包含此功能的 MIK 后，可移除独立的 NoAnyBoom 插件。
