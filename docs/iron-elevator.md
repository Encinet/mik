# 铁块电梯

在同一世界的不同高度放置铁块即可使用，无需命令或登记。同一高度侧面相连的铁块组成平台，斜角不相连；不同平台有重叠的 X/Z 列即可连接，共享楼层列表。

## 使用

- 站在平台上跳跃到上一安全层，按下潜行到下一安全层；保持潜行不连续下行。
- Action Bar 中绿色方向可用，暗灰色不可用；没有安全目标的孤立平台不显示提示。
- 传送只修改 Y，保留 X、Z 和视角，不吸附平台中心。当前垂直落点无铁块或有障碍时，上下行继续寻找下一层；直接选层则不可用。
- 按实际碰撞形状与玩家空间检查落点，排除液体、火等危险位置。可跨楼板，楼层间距不设限制，扫描限于世界建筑高度。
- 成功后清除速度与摔落距离，冷却 0.5 秒。飞行、滑翔、游泳和旁观模式不触发；其他插件可取消传送。

查询中只保留玩家最新一次操作，最长 1.5 秒；离开平台、相关方块变化、卸载或离线会取消待执行请求。没有可用目标时仍可普通跳跃或下马。

模块同时向[场景提示服务](guidance.md#日常随机提示)声明一条日常随机介绍，说明铁块布置与上下行操作，支持全部 16 种语言。玩家无需靠近或使用电梯即可抽中；共享服务负责随机间隔、以一天为基础的递增展示间隔、AFK 避让和持久化，电梯模块无需额外监听或计时任务。

## 拴绳与骑乘

玩家、坐骑、全部乘客及拴绳相连生物作为同行组，支持串联、分支与多层乘坐。非乘客成员须站在同一出发平台，附近无连接的实体不随行。

目标须容纳每名成员，底层成员各自在原 X/Z 下有铁块。整组沿 Y 平移并保留骑乘与拴绳关系，上下行跳过不能容纳整组的楼层。骑乘时只响应新按下的跳跃或潜行；已接受下行请求时阻止本次自动下马。

候选实体只查平台外扩 16 格的已加载范围，最多 1024 个候选、64 名同行成员，超限拒绝。传送前复核关系与落点；中途失败会尝试恢复原位与连接。其他插件可能拒绝恢复，相关失败记录日志。

## 选层面板

井道至少有 3 个可站立楼层时，在平台附近合适的平整墙面显示私有按钮。优先相邻墙，最远搜索 4 格；没有合适墙面时继续使用跳跃和潜行。

对准数字左键或右键选层。当前层为绿色下划线，不可用层为暗灰色；容量不足时分页。面板贴墙并保持可操作高度，不改墙、不生成持久实体。面板整体拦截挖掘和物品使用，点击再次校验墙面、遮挡与落点。

面板每秒刷新，墙面几何缓存两秒；相关方块变化或卸载使缓存失效，离开电梯即移除。

## 楼层编号

普通世界根据周围已加载地表估计入口层，优先稳定的低处地面证据，减少屋顶与孤立深坑影响。确认后的基准在井道内共享，不因换站相邻铁块或加盖屋顶而改变。证据不足时暂用最低可用层并继续重试；下界、末地或无有效地表时也使用最低层。

1 层向上为 2、3……，向下为 −1、−2……，没有 0 层。自动估计无法保证复杂坡地、大屋顶、多入口或悬空建筑准确，可在 `plugins/mik/iron-elevators.yml` 手工指定，重启生效：

```yaml
ground-floors:
  '世界 UUID':
    '铁块 X,铁块 Z': 64
```

值为 1 层铁块的 Y，不是玩家脚部高度。同一井道配置任意一列即可；多列应使用相同高度，冲突时按 X、Z 升序采用第一项。人工值优先，须对应实际可用层；损坏配置会报错。

## 扫描限制

所有世界读取在主线程分批执行，不主动加载区块；每 tick 最多 256 步并协作检查 1 ms 预算。按键查询优先于方向提示和完整目录，多个玩家共享井道发现结果。

每片平台最多 64 块铁块，完整目录最多 128 列、4096 块铁块。完整目录超限不发布，但独立验证通过的局部上下行仍可用；超大连通平台不视为可用平台。

几何缓存有效两秒，最多 64 座井道；相关放置、破坏、爆炸、活塞和区块卸载使其失效。缓存不替代落点、实体碰撞和传送前的实时检查。
